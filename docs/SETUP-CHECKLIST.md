## 1단계 — 오늘: 공지 (출시일을 정하는 일)

약관·방침에 **"변경 시 시행일 7일 전 서비스 내 공지"** 약속이 있습니다.
이번에 방침에 "앱 이용 기록 · 180일"을 추가했는데, 방침 페이지 시행일은 아직 2026-09-10 그대로입니다.

1. 방침 시행일을 **공지일 + 7일**로 정합니다 (오늘 공지하면 **2026-09-22**).
2. 웹 `/admin` 공지로 "개인정보처리방침 개정 안내(시행 9/22) — 앱 이용 기록(익명) 수집 항목 추가"를 게시합니다.
3. 방침 페이지의 시행일·이전 버전 표기를 바꿔 배포합니다 (코드 수정은 요청하면 처리).

1. developer.apple.com → Keys → 예전에 채팅에 붙여넣었던 키를 **Revoke**.
2. 새 키 생성(Apple Push Notifications service) → `.p8` 다운로드(한 번만 가능).
3. Vercel 환경변수 추가 (전부 **Secret**, 채팅으로 보내지 말 것):
   `APNS_KEY_ID`(10자리) · `APNS_TEAM_ID`=`68BP5NY48R` · `APNS_BUNDLE_ID`=`xyz.fcscope.app` · `APNS_PRIVATE_KEY`(.p8 전체)
4. Redeploy.

## 4단계 — 2~3일: TestFlight 실기기 확인

1. Xcode → `FCScope.xcodeproj` → 대상 "Any iOS Device" → Product › **Archive** → Distribute › App Store Connect › Upload.
2. App Store Connect → TestFlight → 내부 테스터에 본인 추가 → 아이폰에서 TestFlight 앱으로 설치.
3. 확인 목록 (TestFlight 판은 **테스트 광고**가 나와야 정상):

- [ ] Apple 로그인 / Google 로그인 후 앱으로 복귀
- [ ] 전적 검색 → 경기·스타일·리포트·선수, 매치 리포트 슛맵 방향
- [ ] 같은 날 **3번째 직접 검색**에서 전면광고 → 닫으면 결과로 이동
- [ ] 배너 광고가 콘텐츠를 가리지 않음
- [ ] 공유 카드(전적·매치) 저장·인스타 공유
- [ ] 위젯 추가 후 값 표시
- [ ] 알림 켜기 → 푸시 수신(2단계 완료 후)
- [ ] 공유 링크(`https://www.fcscope.xyz/...`) 탭 → 앱으로 열림
- [ ] 비행기 모드에서 오류 화면·재시도
- [ ] 글쓰기·신고·차단, 계정 삭제(테스트 계정으로)
- [ ] 설정 › 손쉬운 사용 › 큰 글씨에서 화면 깨짐 없음

문제가 있으면 화면 캡처와 함께 알려주면 수정 → 빌드 번호(`CURRENT_PROJECT_VERSION`)만 올려 다시 업로드.

| 볼 것 | 판단 기준 |
|---|---|
| D1 / D7 재방문율 | 대략 D1 25%↑·D7 10%↑이면 양호(업계 통상 수준, 이 앱 기준치는 첫 2주 값으로 새로 잡기) |

## 참고 — 나중에

- **Cloudflare 이관**: 트래픽이 Vercel 무료 한도에 근접할 때. 걸림돌은 `lib/push/apns.ts`의 `node:http2`·`node:crypto`, `lib/card/render.tsx`의 `next/og`.
- **`match_cache` → R2**: 디스크 IO 장애의 구조적 해결책. 계정 필요.
- **콜드 조회 최대 60초**: 넥슨 API 병렬 제한 때문. 인스턴스당 동시 3 상한 유지.
- **위젯 폰트**: 위젯에는 Pretendard가 번들되지 않아 한글이 시스템 폰트로 표시됨(깨지진 않음).
