# 고도화 전략 (2026-11)

> 2026-10 세션에서 정리한 전략의 요약본. 원본 파일이 저장되지 않아 2026-10-30 에 운영자가 준 요약으로 다시 적었다.

## 진단
- 디자인·분석 기능은 카테고리 1위.
- 그런데 **매일 열 이유**가 없다 — 선수 시세, 스쿼드 BP·급여·팀컬러, 갱신시간·쿠폰 알림. 그래서 다운로드와 리뷰가 안 쌓인다.

## 원칙
- 브랜드 색은 유지한다. 바꾸는 건 정보 구조.
- 탭 재편: **홈 "오늘의 피온" · 전적 · 선수 · 스쿼드 · 커뮤니티** (내 정보는 홈 오른쪽 위로).
- 시세 데이터: **A안** — 시세 없이 출시하고 공식 데이터센터로 연결. **B안**(사용자 입력·기기 내 OCR)은 나중에 실험.
- 백엔드는 별도 저장소 humsleep/fconline 의 `/api/v1`. v1 은 **필드 추가만** 허용(README 규칙).
- 스토어 문구에는 실제로 있는 기능만 쓴다.

## Phase 0 — 측정과 마찰 줄이기 (2026-10-30 완료)
1. 리뷰 요청: 공유 성공 직후 · 3번째 방문 · 승률 상승 주간 푸시 진입. 에러·빈 결과 직후 금지. (`ReviewPrompt`)
2. 검색 전면광고 완화: 내 닉·즐겨찾기·상대 저격 검색 제외, 최소 3분 간격. (`SearchGate`)
3. Analytics: D1/D7 리텐션(`app_open.props.day`), 기능별 사용률(`feature_open`).
4. `docs/STORE-LISTING.md` 에 새 이름·부제·키워드 초안.

## Phase 1 — 매일 열 이유
1. 탭 재편 (위 구조).
2. 홈 "오늘의 피온": 내 폼·지난 방문 이후 새 경기, 즐겨찾기 폼, 급상승 카드, 커뮤니티 인기 글, 주간 성적표.
3. 선수 탭: 픽 랭킹 + 공식 데이터센터 시세 링크(A안).
4. 계산기 허브: 데이터 확인 후 만들 수 있는 것만.

## 이후
- B안 시세 실험, 갱신시간·쿠폰 알림.
