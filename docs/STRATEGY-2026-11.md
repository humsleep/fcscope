## 0. 한 줄 결론

**FC Scope는 "가장 잘 만든 앱"이지만 "매일 열 이유가 없는 앱"이다.**
검색 순위는 디자인이 아니라 **다운로드 속도, 리뷰 수, 키워드 일치**로 정해진다. 이 셋은 결국 매일 쓰는 사용자가 만든다.
FC온라인 유저가 매일 앱을 여는 이유는 **선수 시세, 스쿼드 메이커(팀컬러·급여·BP), 갱신시간·쿠폰·이벤트 알림**이다. FC Scope에는 이 셋이 하나도 없다.
그래서 v2.0의 방향은 디자인을 또 다듬는 게 아니다. **"진단 앱"에서 "FC온라인 매일 도구 + 진단"으로 영역을 넓히는 것**이다.

### 1-2. 문제의 본질 5가지

1. **사용 빈도가 낮은 영역을 골랐다.** 전적 진단은 "졌을 때 가끔" 쓰는 기능이다. 데일리 루프가 없으니 DAU가 낮고, 리뷰가 안 쌓이고, 순위가 안 오른다.
2. **폴리싱에 과투자했다.** 리뷰 회의 5라운드, 아이콘 3세대(시안 30여 장), 프로모 영상까지 만들었지만 신규 유입을 만드는 기능은 0개다. 디자인은 이미 1등이다. 더 다듬어도 순위는 안 바뀐다.
3. **ASO를 계획만 하고 검증하지 않았다.** `ASO-PLAN.md`의 이름 변경("FC Scope: 피온 전적검색·스쿼드 진단")과 리뷰 요청 타이밍이 실제로 적용됐는지, 효과가 측정됐는지 기록이 없다.
4. **경쟁자와 정면으로 붙지 않았다.** "분석은 우리, 시세는 피온북"이라는 포지셔닝은 논리적이다. 하지만 사용자는 앱을 2개 깔지 않는다. 매일 여는 앱이 결국 전적까지 가져간다.
5. **획득 채널이 앱스토어 검색 하나뿐이다.** 공유 카드 QR은 좋은 시작이다. 그러나 커뮤니티(인벤·에펨·디시) 유입, Android, 웹 SEO 퍼널이 비어 있다.

### 1-3. 이미 가진 무기 (버리지 말 것)
- **경쟁자가 아무도 없는 분석 해자:** 슛맵, 랭커 비교, 왜 졌나+처방, 폼 티어, VS 카드
- **공유 카드 9종 + QR:** 바이럴 엔진이 이미 있다
- **위젯, 푸시, 웹 백엔드, 응답 캐시, 번들 선수 인덱스:** 인프라는 경쟁자보다 앞서 있다

## 2. 전문가 회의 (7인 가상 패널)

| 역할 | 핵심 의견 | 우선순위 제안 |
|---|---|---|
| **앱 그로스/ASO 전문가** | "순위 = 7일 설치 속도 + 평점 수 + 키워드 일치. 이름·부제·키워드를 '시세·스쿼드메이커·전적'으로 바꾸고 리뷰 요청을 1주 안에 넣어라. 기능이 생기면 이름에 넣을 단어가 생긴다." | P0 |
| **모바일 게임 리텐션 디자이너** | "데일리 루프는 '확인할 숫자가 매일 바뀌는 것'이다. 시세, 갱신 카운트다운, 오늘의 이벤트·쿠폰, 출석형 스트릭. 홈을 '오늘의 피온' 대시보드로 바꿔라." | P1 |
| **축구 데이터 분석가** | "랭커 데이터와 경기 이벤트는 이미 상위권이다. 실축 폼(API-Football)을 카드 옆에 붙이면 '이번 주 실축 폼 상승 → 카드 주목' 같은 콘텐츠를 매주 만들 수 있다. 경쟁자는 아무도 안 한다." | P2 |
| **하드코어 랭겜 유저(챔스~슈챔)** | "경기 전에 상대 닉 넣으면 포메이션·주 득점 루트·약한 시간대를 보여 줘. 그리고 검색할 때마다 전면광고 뜨면 저격은 웹으로 간다." | P1 |
| **라이트 유저(주 2~3회)** | "스쿼드 짜는 게 제일 재밌다. 팀컬러 몇 단계인지, 급여 남는지, BP 얼마인지만 알려 주면 피온북 지운다." | P1~P2 |
| **UI/UX 디자이너** | "색은 바꾸지 마라. 이미 이 카테고리에서 제일 좋다. 바꿔야 할 건 정보 구조다. 탭 5개 중 '내 정보'를 빼고 '선수(시세·도감)'를 넣어라." | P1 |
| **법무·운영 리스크** | "공식 API에는 시세가 없다. 데이터센터 스크래핑은 약관 위반 소지가 있고 차단 위험도 있다. 경쟁자가 하고 있다고 해서 안전한 건 아니다. 이건 운영자가 결정할 사안이다." | 의사결정 필요 |

**합의:** 색·디자인 전면 교체는 하지 않는다. 대신 **정보 구조와 홈 화면을 대개편**하고 **데일리 기능 3종**을 붙인다. 시세는 데이터 확보 방식을 먼저 결정한다.

## 5. 시세(BP) 데이터 — 운영자 결정 사항

시세는 다운로드를 가장 많이 끌어오는 기능이다. 동시에 공식 API에 없는 유일한 데이터다.

| 안 | 방법 | 장점 | 단점 | 추천 |
|---|---|---|---|---|
| A | **시세 없이 간다.** 공식 데이터센터로 딥링크하고, 계산기·팀컬러·급여만 자체 제공 | 리스크 0, 바로 착수 | 핵심 데일리 루프의 절반을 포기 | 1단계 기본값 |
| B | **크라우드 시세.** 사용자가 "방금 산/판 가격"을 입력하거나, 게임 이적시장 캡처를 올리면 OCR(Vision 프레임워크, 기기 내 처리)로 읽는다 | 약관 리스크 낮음. 커뮤니티 참여 유도 | 초기에 데이터가 희박하다. 인기 선수 위주로만 채워진다 | **2단계 추천** |
| C | **데이터센터 수집**(서버, 저빈도, 인기 선수 한정, 캐시) | 경쟁자와 같은 품질 | 약관 위반 소지, IP 차단, 서비스 중단 요청 위험. 앱 심사 5.2(지식재산) 리스크 | 운영자 판단. 하려면 넥슨에 제휴·허가를 먼저 문의 |

**권장:** A로 1단계(계산기·팀컬러·급여·저격)를 먼저 출시한다. 그다음 B를 실험한다. C는 넥슨에 문의한 결과를 보고 정한다.

## 6. UI/UX 대개편안

### 6-1. 정보 구조 (탭 재편)
| 현재 | 변경 | 이유 |
|---|---|---|
| 전적 · 스쿼드 · 픽 랭킹 · 커뮤니티 · 내 정보 | **홈 · 전적 · 선수 · 스쿼드 · 커뮤니티** | "내 정보"는 우측 상단 아바타로 옮긴다(토스·인스타 방식). "픽 랭킹"은 "선수" 탭 안으로 넣는다 |

- **홈 = "오늘의 피온"** (새로 만듦)
  1. 내 폼 카드(즐겨찾기 구단주, 폼 티어, 연승)
  2. **갱신시간 카운트다운 · 오늘의 이벤트/쿠폰**
  3. 관심 선수 시세 변동(B안 이후)
  4. 오늘의 급상승 카드(기존 `movers`)
  5. 커뮤니티 핫 배틀 1개
- **전적 탭:** 검색 히어로, 최근 검색, **"경기 전 상대 저격"** 입력칸
- **선수 탭:** 검색 → 선수 도감(랭커 성적 + 유저 평가 + 실축 폼 + 시세) / 픽 랭킹 / 계산기 허브(수수료·강화·급여)
- **스쿼드 탭:** 기존 빌더 + 하단 고정 **요약 바**(팀컬러 단계 · 급여 n/310 · 구단 가치) + "내 스쿼드" 목록

### 6-2. 색·비주얼
- **브랜드 색은 유지한다**(인디고 + 오렌지→마젠타 그라디언트). 카테고리 1위 수준이고, 아이콘·스토어·공유 카드와 일관된다. 또 바꾸면 그동안 쌓은 인지도가 사라진다.
- 바꿀 것:
  - 데이터 화면의 정보 밀도를 높인다(피온북 사용자는 "숫자 많은 화면"에 익숙하다). 표 모드와 카드 모드 토글을 둔다.
  - 시세 상승·하락 색 규칙을 정한다. 한국 관례에 맞춰 상승=빨강, 하락=파랑으로 하고, 승패색(win/lose)과는 분리한다.
  - 강화 단계 배지 컬러(1~13강)를 게임 내 색과 맞춘다.
- 카피 톤: 해요체를 유지하되, 결과 화면은 짧은 밈 톤을 허용한다(round 1~5에서 합의된 범위).

### 6-3. 광고 정책 조정
- 검색 전면광고(`SearchGate`)는 **내 닉 · 즐겨찾기 · 상대 저격 검색에서 제외**한다. 전면광고는 세션 3번째 화면 전환부터, 최소 3분 간격으로만 띄운다.
- 보상형 광고를 도입한다. "광고 보고 상대 저격 리포트 상세 열기", "시세 알림 슬롯 +3개" 같은 방식으로 수익을 보전한다.
- 광고 제거 인앱결제(월 1,900원 수준)를 검토한다. 피온북의 광고 불만 사용자를 흡수하는 장치다 [추정].

## 7. 단계별 로드맵

### Phase 0 — 1주 · "순위 바닥 다지기" (코드 소량)
| 작업 | 상세 |
|---|---|
| 메타데이터 교체 | 이름 `FC Scope: 피온 전적·스쿼드·계산기`(기능 출시 후 "시세"로 교체) · 키워드 `피파4,FCO,엪온,구단주,전적검색,감독모드,수수료,강화,팀컬러,급여` (2.3.1 위반이 없도록 **출시한 기능만** 넣는다) |
| 리뷰 요청 | `requestReview`를 공유 성공 직후, 3번째 방문, 승률 상승 주간 푸시 진입 시에 띄운다(`ASO-PLAN` §5-2 실행) |
| 전면광고 완화 | §6-3 |
| 측정 대시보드 | 기존 `Analytics`에 D1/D7 리텐션, 기능별 사용률, 공유→설치 지표 추가 |

### Phase 1 — 3~4주 · "매일 여는 이유" (v2.0)
1. 홈 "오늘의 피온" + 탭 재편(§6-1)
2. 계산기 허브: 수수료(할인 조합) · 강화 시뮬(공시 확률) · 급여 계산
3. 갱신시간·이벤트·쿠폰 캘린더(웹 어드민에서 운영자가 입력) + 푸시 + 잠금화면 위젯
4. **경기 전 상대 저격 리포트**(넥슨 API만 사용)
5. 스쿼드 빌더: 팀컬러 판정·급여 합계(운영자 큐레이션 데이터) + 내 스쿼드 서버 저장

→ 이 시점에 이름·부제에 "스쿼드메이커·계산기·저격"을 넣을 수 있다. **인앱 이벤트**("26-27 팀컬러 개편 대응 스쿼드메이커")를 함께 띄운다.

### Phase 2 — 4~6주 · "데이터 해자"
1. 시세 B안(크라우드 + 기기 내 OCR) 실험 → 관심 선수 시세 알림
2. 선수 도감 2.0: 랭커 성적 + 유저 평가·후기 + 실축 폼(API-Football) + 리뷰 영상(YouTube)
3. 슛맵 xG(StatsBomb 데이터로 학습한 경량 모델)
4. 자체 집계 "고등급 유저 사용 선수·포메이션"(`fconline/v1/match` 샘플링)

### Phase 3 — 6주~ · "채널 확장"
1. **Android**: fcscope.xyz를 TWA로 감싸 Google Play에 먼저 출시(M). 지표가 좋으면 네이티브(Kotlin/Compose)로 전환
2. 커뮤니티 시딩: 인벤·에펨·디시에 주 1회 데이터 글("이번 주 랭커 1픽", "팀컬러 개편 가성비 스쿼드")
3. 시즌 업적·배지, 친구 리그(주간 승점표), 치지직 라이브 카드
4. 웹 SEO: 선수·구단주 페이지를 정적 생성 → 검색 유입 → 스마트 앱 배너
