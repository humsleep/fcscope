## 0. 한 줄 결론

카드형 피드를 버리고 **에펨·인벤·더쿠식 "제목 한 줄 + 메타 한 줄" 리스트**로 간다(한 화면 3개 → 10개).
상세는 **작성자 줄을 제목 바로 밑으로**, 신고·차단은 `⋯` 메뉴로. 댓글은 말풍선 상자를 걷어내고
**인스타·스레드식 평면 + 1단 답글 + BEST 고정 + 작성자 배지 + 바닥 고정 입력창**.
글자 크기는 "렌더 기준"으로 다시 잡는다 — 지금 커 보이는 진짜 원인은 아래 1-2.

### 1-2. "글자가 크다"의 진짜 원인

`Theme.swift` 의 `TypeScale.readable()` 이 20pt 미만 글자를 **전부 ×1.15** 한다. 그래서 코드상 숫자와 실제 렌더가 다르다.

| 요소 | 코드 | **실제 렌더** | 벤치마크(에펨·인벤·클리앙 모바일 실측) | v2 |
|---|---|---|---|---|
| 목록 제목 | `fcFont(15, .bold)` | **17.3pt Bold** | 14~16px Regular | **15pt Medium** |
| 목록 미리보기 | `fcFont(13)` | 15pt | 없음 | **없음** |
| 상세 본문 | `fcFont(16)` | **18.4pt** | 15~16px | **16pt / 행간 26** |
| 댓글 본문 | `fcFont(15)` | 17.3pt + 상자 | 14~15px | **15pt / 행간 22** |

→ 커뮤니티 화면은 **보정 없는 렌더 크기 토큰**(아래 3-2)을 쓴다. 다른 화면의 `readable()` 정책은 건드리지 않는다.

### 3-2. 글자 — 렌더 기준 토큰 `fcText(_:)`

새 modifier: `pretendard(size × TypeScale.factor(dynamicTypeSize))` — **`readable()` ×1.15 보정을 거치지 않는다.** Dynamic Type 은 그대로 따른다(최대 1.6배).

### 3-3. 간격

4pt 그리드. 화면 좌우 여백 16. 목록 행 상하 11 + 줄 간 5 → **행 높이 ≈ 63pt**(1줄 제목 기준). 상세 섹션 간 14~16, 본문↔댓글 사이 8pt 띠(`surface` 채움 + 위아래 hair).
반경: 카드 14 · 배틀 카드 18 · 태그 5 · 칩/버튼 캡슐.

## 4. 정보 구조

```
커뮤니티 (큰 제목 · 🔍 · 🔔)
├─ 전체          지금 뜨는 글 3줄 → 광고 1 → 최신 목록
├─ 인기 HOT      24h 점수순(백엔드 sort=hot). 서버가 지원 전이면 탭 자체를 숨김
├─ 스쿼드        2차 칩: 전체 · 자랑 · 평가 · 만들어줘 · 배틀
└─ 클럽·대회     2차 칩: 전체 · 클럽모집 · 클럽전 · 대회
```

- 7개 유형을 한 줄 칩 더미로 늘어놓던 것을 **1차 탭 4개 + 그룹 안 2차 칩**으로. 2차 칩은 최대 5개라 한 줄에 들어간다 — 기존 "가로 스크롤 금지" 원칙 유지.
- 2차 칩 아래 정렬 줄: `새 글 24개 · 오늘` / `최신순 ▾`(최신순·댓글순; 인기순은 백엔드 후).
- 🔔 은 기존 `/api/me/notifications` 진입(내 글에 달린 새 댓글). 🔍 은 백엔드 `q` 추가 후 활성화 — 그 전엔 아이콘을 두지 않는다.
- 탭·칩 상태는 `@SceneStorage` 로 기억(다시 들어와도 같은 탭).

## 5. 목록 행 (mockups `01-list-a/b.png`)

```
┌ 16 ─────────────────────────────────────────────── 16 ┐
│ [평가] 도르트문트 팀컬러 4-2-3-1 평가 부탁드려요 🛡 [12] │  ← 1줄, 말줄임
│ 보엠✓ · 3분 전 · 조회 248 · 추천 9                       │  ← 12pt faint
└───────────────────────────── hair 1px ─────────────────┘
```

| 부분 | 규칙 |
|---|---|
| 말머리 태그 | 짧은 이름(자랑·평가·만들어줘·배틀·클럽모집·클럽전·대회). **색은 3계열만** — 스쿼드 계열 tint, 배틀 coral, 클럽·대회 teal. 마감 글은 태그가 `마감`(faint)으로 바뀐다. 배경은 같은 색 10~14%. |
| 제목 | `rowTitle`, `lineLimit(1)`. Dynamic Type `.accessibility1` 이상이면 `lineLimit(3)`. **읽은 글은 `muted`**(글 ID 를 로컬 `LocalPrefs` 에 최근 500개 저장). |
| 첨부 글리프 | 스쿼드 첨부면 방패 SF Symbol(`shield.fill`) 15pt faint. 이모지 "🧩 스쿼드" 텍스트는 제거. |
| `[12]` | `commentCount > 0` 일 때만. 0이면 생략(빈 `[0]` 은 소음). |
| 메타 | 닉 `muted` Medium + 인증 `✓`(tint) + 운영자 배지 · 상대시간 · `조회 N`(필드 있을 때) · `추천 N`(필드 있고 >0). 1만 이상은 `1.2만`. 추천 ≥50 이면 coral. 지역(클럽 글)은 메타 끝에 `· 서울`. |
| 탭 영역 | 행 전체. 길게 누르면 컨텍스트 메뉴(공유 · 신고 · 작성자 차단) + 미리보기(제목+본문 3줄). |
| VoiceOver | 행 하나를 한 요소로: "스쿼드 평가. 도르트문트 팀컬러… 댓글 12개. 보엠, 3분 전." |

**지금 뜨는 글 상자**: `surface` 카드, 헤더 "🔥 지금 뜨는 글"(coral 12.5 Bold) + "더보기"(→ 인기 탭), 순위 Chakra 숫자 + 제목 14 Medium + `[n]`, 3줄 고정 28pt 간격. 서버 hot 데이터가 없으면 상자를 그리지 않는다.

**광고**: 운영자 결정(2026-09-21 "탭 바로 아래·목록 맨 위 카드 하나")은 유지하되, 320×100 배너 카드 대신 **행 높이(58pt)의 네이티브 광고 행** 또는 320×50 적응형 배너를 권장 — 지금 배너가 첫 화면의 1/4을 차지한다. *(광고 형식 변경은 운영자 승인 필요 — 제안 사항)*

**글쓰기 FAB**: 우하단, 탭 바 위 18pt. 브랜드 그라디언트 캡슐 50pt, `✎ 글쓰기` **17pt Bold**(흰 글자 AA 큰 텍스트 조건). 아래로 스크롤하면 원형(50×50)으로 줄고 위로 올리면 펼친다. 상단 툴바의 글쓰기 아이콘은 제거(중복).

**페이지네이션**: 기존 "바닥에서 다음 장" 유지. 끝이면 `다 봤어요 👀`.

## 6. 상세 (mockups `02-detail-a.png`)

위에서 아래로:

1. **내비게이션**: ‹ · 가운데 말머리 이름(15 SemiBold muted) · `⋯` 메뉴(내 글: 삭제 / 남의 글: 신고 · 작성자 차단 · 링크 복사). **상세에선 탭 바를 숨긴다**(`.toolbar(.hidden, for: .tabBar)`) — 입력창 자리.
2. **머리**: 말머리 태그 → 제목 `detailTitle`(여러 줄 허용, `textSelection`).
3. **작성자 줄**(맨 아래에서 이동): 아바타 36(닉 첫 글자 + 닉 해시 색 8종) · 닉 14 SemiBold ✓ 운영자 · `3분 전 · 조회 248` 12 faint · 오른쪽 `전적 보기 ›` tint 캡슐(인증 닉 있을 때만 → `router.push(.user(v))`). FC Scope 만의 연결고리.
4. **메타 표**: `metaRows` 를 2열 그리드 카드(라벨 11.5 faint / 값 14 SemiBold). 위치(`region`)·포지션(`positions` 칩)도 같은 표에.
5. **본문**: `body` 16 / 행간 26 / `ink2`. URL 자동 링크(tint). 2000자 상한이라 접기 없음.
6. **첨부 스쿼드 카드**: 미니 피치 썸네일(52×64, 슬롯 x/y 점) + `첨부 스쿼드` / 스쿼드 이름 15 SemiBold / `4-2-3-1 · 11명`. 데이터는 기존 `GET /api/squad/:id`(이미 계약에 있음)로 지연 로드, 실패하면 이름 없이 "첨부 스쿼드 보기" 카드로 폴백.
7. **배틀 카드**(배틀 글) — 8절.
8. **연락**(클럽 글): `연락` 라벨 + 값(복사 버튼).
9. **행동 줄**: `♡ 추천 9`(캡슐, 누르면 coral 채움 + 하트 bounce) · `💬 댓글 12`(누르면 댓글로 스크롤 + 입력창 포커스) · 오른쪽 공유(브랜드 그라디언트 원 36). 추천 필드가 오기 전엔 추천 캡슐을 숨긴다.
10. **광고 1개** — 행동 줄 아래·댓글 위. "본문 중간 금지" 원칙은 유지(본문이 끝난 뒤). *(위치 이동은 운영자 확인 필요 — 지금은 화면 맨 위)*
11. **8pt 띠** → 댓글 섹션(7절).

## 7. 댓글 (mockups `02-detail-a/b.png`)

**헤더**: `댓글 12`(숫자 tint Chakra) · 오른쪽 `등록순 | 최신순`. 기본은 **등록순**(대화 흐름) + 위에 BEST 고정. *(회의에서 "추천순 기본"을 기각 — BEST 와 중복)*

**BEST**: 추천 3 이상 상위 2개를 맨 위에 복제 고정. 왼쪽→오른쪽 골드 10% 그라디언트 띠 + `BEST` Chakra 배지(골드 채움, 다크 글자). 원래 위치에도 그대로 남는다(에펨 방식). 댓글이 5개 미만이면 BEST 없음.

**댓글 행**
```
(아바타30) 닉 [작성자] [운영자] · 2분 전                 ⋯
           본문 15pt / 행간 22 (상자 없음, ink2)
           [🛡 제안 스쿼드 보기]           ← squadId 있을 때 캡슐
           ♡ 14    답글 달기
```
- **작성자 배지**: `comment.authorId == post.authorId` 면 tint 외곽선 `작성자` — **지금 데이터로 바로 가능**.
- **인증 ✓**: 댓글 작성자 인증 닉은 백엔드 필드 추가 후.
- **⋯**(44×44): 내 댓글 = 삭제(확인 알림) / 남의 댓글 = 신고 · 작성자 차단 · 복사. 지금의 행 안 "삭제" 텍스트 버튼은 메뉴로 들어간다.
- **하트**: 탭 = 토글(낙관적 업데이트 + `.sensoryFeedback(.impact(weight: .light))`), 내 하트는 coral 채움. 길게 누르기 = 복사.
- **답글 달기**: 탭하면 입력창 포커스 + 답글 대상 띠.

**답글(1단)**: `parentId` 가 있으면 부모 아래 들여쓰기 54pt, 아바타 24, 왼쪽에 `ㄴ` 모양 연결선(line 1.5pt, 둥근 모서리). 본문 앞 `@부모닉` tint SemiBold. 답글의 답글도 같은 단(1단 평면화, 인스타 방식). 답글 3개 초과 시 2개만 보이고 `── 답글 3개 더 보기`.
*`parentId` 가 오기 전*: 클라이언트는 평면 목록만 그리고 "답글 달기"는 `@닉 ` 을 입력창에 미리 채우는 것으로 대신한다(서버 변경 없이 동작).

**입력창(바닥 고정)**: `safeAreaInset(edge: .bottom)` + `.bar` 머티리얼 배경 + 위 hair.
- 상태별: 비로그인 → 필드 자리에 `로그인하고 댓글 달기` 버튼(로그인 시트) / 닉 없음 → `닉네임 등록하고 댓글 달기 →`(내 정보 탭) / 정상 → 필드.
- 필드: `surface2` 캡슐 40pt, 1~5줄 자동 확장, 플레이스홀더 `댓글 달기…`.
- 왼쪽 방패 버튼: 내 스쿼드 첨부 — 댓글 POST 가 `squad_id` 를 **이미 받는다**(`app/api/community/posts/[id]/comments/route.ts`). 서버 변경 없이 v2.0 에 포함.
- 전송: 원 40, 비어 있으면 `surface2`/faint, 입력 있으면 브랜드 그라디언트 + 흰 화살표(아이콘이라 3:1 기준 통과). 전송 중 스피너, 성공 시 `.success` 햅틱 + 새 댓글로 스크롤 + 0.6s 하이라이트.
- 답글 모드 띠: `@피파탐색이님에게 답글   ✕`.
- 300자 넘으면 오른쪽에 남은 글자 수.

## 14. API — 있는 것 vs 필요한 것

`/api/v1` 은 **필드 추가만** 가능. 앱은 새 필드를 전부 **옵셔널**로 선언하고, 없으면 그 UI 를 숨긴다(구 서버·신 앱 / 신 서버·구 앱 모두 안전).

### 14-1. 이미 있음 — v2 1차는 이것만으로 출시 가능

| 화면 요소 | 필드 |
|---|---|
| 목록 행 | `Post.id/type/title/status/created_at/comment_count/squad_id/region/author{nickname, verifiedNickname, isOperator}/typeLabel/typeEmoji` |
| 탭·칩·글쓰기 | `types[].type/label/emoji/blurb/accent/fields/template/bodyLabel/bodyPlaceholder` |
| 상세 | `body/metaRows/positions/contact/squadB/viewer{loggedIn,isOwner,canComment}` |
| 댓글 | `Comment.id/post_id/author_id/body/squad_id/created_at/author{nickname,isOperator}/isOwn` |
| **작성자 배지** | `comment.author_id == post.author_id` (클라이언트 계산) |
| 첨부 스쿼드 카드·배틀 이름 | `GET /api/squad/:id` (`name/formation/slots`) |
| 배틀 | `GET/POST /api/community/battle` `{a, b}` |
| 글쓰기 스쿼드 선택 | `GET /api/profile` `squads[]` |
| 알림 🔔 | `GET /api/me/notifications` |

`Post.preview`(목록 미리보기)는 v2 앱이 **읽지 않지만 서버는 계속 내려보낸다**(구 앱 계약).

### 14-2. 추가가 필요한 것 (모두 옵셔널 · 추가만)

| 우선 | 필드/파라미터 | 위치 | 용도 | 서버 작업 |
|---|---|---|---|---|
| P1 | `view_count: int?` | `Post`(목록·상세) | 메타 `조회` | 컬럼 + 상세 GET 시 증가(봇·같은 기기 중복 제외; Workers 외부호출 한도 고려해 RPC 1회) |

| P1 | `POST/DELETE /api/community/posts/:id/like` | 신규 쓰기 라우트 | 추천 토글 | `{ likeCount, liked }` 반환 |

| P2 | `sort=new|hot|comments` 쿼리 | `GET /api/v1/community/posts` | 인기 탭·정렬 | 쿼리 파라미터 추가는 비파괴. hot = (추천×2+댓글)÷(경과시간+2)^1.5, 24h |
| P2 | `types=a,b` 쿼리 | 같은 라우트 | 그룹 탭(스쿼드/클럽·대회) | `in` 필터. 그 전엔 그룹 탭을 클라이언트에서 병합하지 말고 2차 칩 단일 type 으로만 동작 |
| P2 | `hot: [Post]?` 또는 `isHot: bool?` | 목록 응답 최상위 / Post | 지금 뜨는 글 3줄 | page=1 일 때만 3개 |
| P2 | `shortLabel: string?` | `types[]` | 말머리 태그 짧은 이름 | 그 전엔 앱 내 매핑 테이블(type→짧은 이름) 사용 |
| P2 | `mine: "A"\|"B"\|null` | `GET /api/community/battle?voter=` | 재방문 시 내 표 | contract.ts 의 "mine 은 서버가 주지 않는다" 갱신 |

배포 순서: 서버(마이그레이션 + 필드) → `npm run verify:api` → 앱. `lib/api/contract.ts` 에 새 필드는 전부 `'?'` 로 선언.

- 상세: 댓글 입력을 `safeAreaInset(edge: .bottom)` 로 빼고 `@FocusState`. `ScrollViewReader` 로 새 댓글/댓글 섹션 이동.
- `fcText(_ role:)` 를 `Theme.swift` 에 추가(지금 다른 작업이 Theme.swift 를 고치는 중 — 병합 후).
- 읽음·초안·내 투표는 `LocalPrefs` 확장(최근 500개 링버퍼).
- 광고 `AdSlot` 위치·형식 변경은 운영자 승인 후.
