# 심사 거절 대응 — Build 12 → 15 / 2026-09-30

심사 기기: iPad Air 11" (M3), iPadOS 27.2. 지적 두 건.

## 1. Guideline 2.3.6 — 연령 등급의 "사용자 생성 콘텐츠"

커뮤니티(글·댓글)가 있으니 **"User-Generated Content: Yes"** 여야 한다. 코드 수정 없음.

App Store Connect → 앱 → **앱 정보** → 연령 등급 → 편집 → "사용자 생성 콘텐츠" **예** → 저장.
(등급이 올라갈 수 있다 — 그대로 둔다.)

## 2. Guideline 2.1 — ATT 팝업을 찾을 수 없음

**원인**: ATT 를 "첫 전적 검색 결과를 본 뒤"에만 물었다(`RecordView` → `requestConsentIfEligible`).
심사자는 검색을 하지 않아 팝업을 끝내 보지 못했다.

**수정(Build 15)**: 온보딩을 마치고 메인 탭이 처음 뜨면 1초 뒤 UMP → ATT → AdMob 시작
(`RootView` → `AdsManager.requestConsentOnLaunch`). AdMob SDK 는 ATT 응답 이후에만 시작하므로
팝업 전에 광고 식별자가 쓰이지 않는다. 시뮬레이터 새 설치로 확인함.

### 녹화 대본 (실제 기기, 최신 iOS, 1분 내외)

1. 앱 **삭제 후 재설치**(또는 설정 › 개인정보 보호 › 추적 › "앱이 추적을 요청하도록 허용" 켜져 있는지 확인)
2. 앱 실행 → 인트로(약 1.4초) → 온보딩 3장 "다음" → "시작하기"
3. 약 1초 뒤 **ATT 팝업** → "허용" 또는 "앱에 추적 금지 요청"
4. 홈 → 검색창에 `보엠` → 전적 결과(상단 배너 광고가 이때 보임)

⚠️ 설정의 "앱이 추적을 요청하도록 허용"이 꺼져 있으면 팝업이 아예 뜨지 않는다. 녹화 전에 확인.

### 제출 순서

1. `CURRENT_PROJECT_VERSION` 15 으로 아카이브 → 업로드
2. 연령 등급 UGC "예" 저장
3. 심사 메시지 답장 + **앱 심사 정보 → 메모**에 아래 영문 붙여넣기, 녹화 첨부
4. 새 빌드(15)를 선택해 다시 제출
