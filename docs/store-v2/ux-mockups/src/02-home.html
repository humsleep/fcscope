현재 첫 화면: 슬로건 → 빈 광고 자리(약 110pt) → “처음이신가요?” → 급상승 → 칩. 검색창은 네비 바 안의 회색 필드라 주인공이 아니다. 첫 사용자가 해야 할 일이 3초 안에 안 보인다.

1
검색을 히어로 카드 안으로. 그라디언트 테두리 + “진단 ▶” 버튼. 카피는 기능 나열(“전적·슛맵·선수 성적표…”) 대신 유저의 질문(“나 요즘 왜 지는지”).
2
예시 리포트를 결과물 미리보기로. “처음이신가요?” 텍스트 카드 → 실제 공유 카드 썸네일. 결과가 어떻게 생겼는지 보여줘야 입력한다(토스·무신사 “미리보기 먼저” 패턴).
3
급상승·검색 칩은 한 줄 가로 스크롤. 지금은 칩이 3~4줄 쌓여 탭 바 밑까지 밀린다.
4
광고는 첫 스크롤 아래. 매출 위치를 유지하되 “첫 3초” 영역에서만 뺀다. 로딩 중 회색 빈 박스가 첫인상을 깎는다(캡처 참고).
