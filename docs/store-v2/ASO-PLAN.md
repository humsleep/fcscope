→ 카테고리는 **스포츠 유지**. 피온북·마이피온·스쿼드매니아는 게임 카테고리라, 스포츠 무료 차트 진입 경쟁이 훨씬 약하다.

### 2-1. 상표 리스크 판단
| 단어 | 소유 | 이름에 넣을 때 위험 | 근거 |

| 피파 | FIFA | **중~상** | FIFA는 상표 집행이 적극적이다. 이름에는 넣지 않는다. 키워드 필드에만 넣을지는 아래 참조 |

→ **이름 = "피온", 부제 = "FC온라인"(이미 심사 통과), 키워드 = 나머지.** 이렇게 하면 두 검색어를 모두 잡으면서 상표 표면은 이미 통과한 부제 하나로 유지된다.

> 토큰화 메모: Apple 검색은 이름·부제·키워드의 단어를 조합해 매칭한다. 한국어 합성어는 부분 매칭이 약하다(추정 — `전적검색` 하나로 `전적`이 잡힌다고 보장할 수 없음). 그래서 이름에 `전적검색`, 키워드에 `전적`·`검색`을 따로 둔다. `·`는 구분자로 처리되는 것으로 보이지만 확실히 하려면 `전적검색 · 스쿼드 진단`처럼 공백을 둔다(26자, 한도 안).

## 3. 변경 절차 · AdMob 연결 (실무)

1. **이름·부제는 새 버전 제출 때만 바뀐다.** Apple 문서: 이름은 첫 심사 제출 전까지 자유 편집, 이후에는 "새 버전을 만들거나 버전 상태가 편집을 허용할 때"만 바꿀 수 있다. 부제도 같은 규칙(앱 정보 영역이지만 라이브 버전이 있으면 잠김 → 새 버전 "제출 준비 중" 상태에서 열린다).
   - 즉 **1.0.1(버그 수정이라도)을 만들어 이름·부제·키워드·스크린샷을 한 번에 바꾼다.** 키워드·설명·스크린샷도 버전 메타데이터라 같이 묶인다.
   - **프로모션 텍스트만은 심사 없이 언제든 수정 가능** → §4 문구는 오늘 바로 반영.
2. **AdMob 앱 검색이 안 되는 이유**: 출시 직후에는 스토어 색인 지연이 있고(보통 수일), KR 전용 앱은 AdMob 검색에 늦게/잘 안 잡히는 경우가 흔하다.
   - 해결: AdMob → 앱 → (앱 설정) **"스토어에 연결"/"앱 스토어 세부정보 추가"** 에서 앱 이름 대신 **App Store ID `6812981907` 또는 URL `https://apps.apple.com/kr/app/id6812981907`** 로 검색한다. 그래도 안 뜨면 "게시되지 않은 앱"으로 등록해 두고 며칠 뒤 다시 연결.
   - 연결 후 app-ads.txt 검증은 **App Store의 "마케팅/지원 URL" 도메인**(fcscope.xyz)에서 `/app-ads.txt` 를 읽는다. 웹 저장소에 `app/app-ads.txt/` 가 이미 있으니 퍼블리셔 ID 줄이 맞는지만 확인.
   - **이름을 바꾸면 AdMob에 표시되는 앱 이름은 자동 갱신**(스토어 ID로 묶여 있으므로). 이름 변경을 AdMob 연결과 기다릴 필요 없다.
3. **미국 스토어 출시는 하지 않는다.** AdMob 색인용으로 열 필요가 없고(ID로 연결 가능), 한국 서버 데이터만 다루는 한국어 앱을 미국에 열면 저평점 리뷰·4.2 지적 위험만 늘어난다.

```
구단주명만 입력하면 최근 경기의 슛맵·선수 성적표·스쿼드 점수가 바로 나와요. 로그인 없이 무료.
"왜 지는지"를 넥슨 상위 랭커 기록과 비교해서 알려 드려요.
```
- 1줄: 검색어(`피온 전적검색`) + 차별점(진단). 2줄: 입력 1개 → 결과 3개 + 마찰 제거(로그인 없음). 3줄: 경쟁 앱에 없는 근거(랭커 기록).
- 나머지 본문은 현재 설명을 유지하되 `■ 선수 성적표` 블록을 `■ 전적 진단` 바로 다음(2번째)으로 올린다.

### 스크린샷 순서(같은 1.0.1에 반영)
검색 결과에는 **첫 3장**만 보인다. 지금 1번이 "홈"이라 가치가 안 보인다.
1. **슛맵** — 헤드라인 "내 슛 vs 상대 슛, 한 장에" (03-match-report)
2. **랭커 대비 선수 성적표 + 클리닉 점수** — "내 선수, 랭커 기준 몇 점?" (04-players)
3. **전적 진단** — "구단주명 하나로 최근 30경기 진단" (02-record)
4. 공유 카드(인스타 스토리) — 현재 스크린샷에 없음, **새로 만들 것**
5. 스쿼드 빌더(최근 선발 불러오기) 6. 픽 랭킹 7. 위젯(잠금·홈 화면) — 새로 만들 것
- 상단 30% 영역에 큰 한국어 헤드라인 + 하단에 실제 화면. 다른 이용자 닉네임은 블러 처리(기존 ⚠️ 해소).
