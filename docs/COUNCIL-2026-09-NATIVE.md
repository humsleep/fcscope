# 네이티브 앱 전환 회의 (2026-09-04)

참석(에이전트 페르소나): iOS 시니어 아키텍트 · 게임 커뮤니티 기획자(FC온라인 헤비 유저) · 그로스 마케터 + iOS 디자이너 · 유저 패널 3인(헤비/라이트/덕후).
안건: Capacitor 웹뷰 셸(legacy-capacitor/)을 버리고 **완전 네이티브 SwiftUI 앱**으로 재구축하면서, 웹 대비 "매일 열 이유"를 만들고 App Store 심사를 통과한다. 무료 + AdMob.

## 합의 결론 (실행 순서)

| 순위 | 결정 | 근거(누가) |
|---|---|---|
| 1 | **닉네임 검색 → 전적 5탭(경기 기록·종합 리포트·선수 성적표·플레이스타일·이적시장), 로그인 벽 없음** | 전원. "이게 없으면 앱이 아님" |

| 7 | 광고: **전적 화면엔 배너 금지**, 메타·커뮤니티 하단 적응형 배너 1곳 + 목록 네이티브 광고. 보상형(AI 진단 재실행 등)은 2차. **첫 실행 3일 광고 0, ATT는 첫 검색 결과를 본 뒤** | 유저 패널 "첫 실행 UMP→ATT→로그인 연속 팝업 = 삭제" |
| 8 | 스쿼드 빌더: 1차는 **탭-배치 + 프리셋 + 닉네임 임포트 + 저장/공유**, 자유 드래그는 2차 | 아키텍트 난이도 4/5, 덕후 "폰에서 드래그는 고통" |
| 9 | 커뮤니티: 읽기 + 글/댓글 + 신고·차단(로컬) 유지. 유튜브 스트립은 제외 | 헤비 "유튜브는 유튜브 앱이 함" |
| 2차 | 친구 리그(주간 승점표), 시즌 업적/뱃지, 라이벌 감시 푸시, 오프라인 SQLite 누적 분석, Live Activity(스쿼드 배틀), App Intents/Spotlight, 보상형 광고 | 기획자 TOP3 중 친구 리그, 덕후 요청 |

## 아키텍처 (아키텍트)
- iOS 17+, SwiftUI + `@Observable` MVVM. TCA 도입 금지(1인 운영).
- supabase-swift(인증: Apple `signInWithIdToken`, Google PKCE) → `/api/v1` JSON은 **Bearer JWT**. 웹의 `createClient()`가 Bearer 를 받도록 확장(완료).
- URLSession async/await 자체 래퍼, `ApiError.code` enum 매핑, `Retry-After` 존중. Nuke(LazyImage) 이미지. Swift Charts. google-mobile-ads SPM + UMP.
- 딥링크: `/user/:nick` `/match/:id` `/player/:spid` `/community/:id` `/squad/:id` → Route enum → NavigationStack. `fcscope://` 는 OAuth 복귀 전용.
- 위험: 콜드 조회 최대 60초(프로필 즉시 + 매치 후속 2단계, 즐겨찾기 프리워밍 크론), 인증 이원화, 니치 시장 eCPM.
