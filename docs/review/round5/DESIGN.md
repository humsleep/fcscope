## 0. 판정 — **FIX (must-fix 2건)**

광고 배치 자체(위치·빈도·라벨·컨테이너)는 설계대로 잘 들어갔다. 광고가 섹션 경계에 놓여 흐름을 끊지 않고, `AD · 광고` 카드가 본문 Panel 과 같은 문법이라 싸구려처럼 보이지 않는다.
다만 **배너 뷰의 검은 레터박스**가 4개 화면에서 보이고, **홈(Max) 첫 화면에서 광고가 탭 바에 붙어 멈춘다.** 이 둘만 고치면 승인한다.

## 3. 4라운드 수정 확인 (전부 해결)

| 항목 | 결과 |
|---|---|
| 폼 스트립 무게 비대칭 | 해결 — 승·패 모두 틴트, 몰수는 점선 테두리, 최근 경기는 외곽선. 범례도 붙었다(`max-*-record-formstrip`). |
| AX5 요즘 흐름 띠 폭 | 해결 — 띠 좌우가 아래 타일과 맞는다(`se-ax5-*-record-nowband`). |
| 글쓰기 양식 중복 | 해결 — 점선 `+ 양식 넣기` 하나, 액세서리 바는 첨부만(`compose-single-template`). |
| 답글 연결선 | 해결 — 형제 답글이 세로선 하나로 이어진다(`community-replies-connector`). |
| 스쿼드 4-3-3 CM | 해결 — 가운데 CM 이 센터서클과 겹치지 않는다. 카드 GK 도 수비 라인과 떨어진다(`cards/squad-*`). |
| 로그아웃 내 정보 | 해결 — 혜택 4줄 + 로그인 CTA. 광고 없음(설계 1-9 준수). |
| VS 404 장식 | 해결 — `4:04` 대신 물음표 인물 아이콘. |
| 첨부 같은 닉네임 규칙 | 해결 — 대소문자만 다른 이름을 막고 이유를 설명한다. |
