## A. 준서 (18, 랭겜 빡겜러) — 6.5/10

**첫인상 10초:** 홈 헤드라인 "나 요즘 왜 지는지, 30경기로 바로 진단" — 이건 내 말임. 저번 "감이 아니라, 데이터로"(학원 광고)보다 훨씬 나음. 근데 **검색창이 두 개**(상단 "구단주명 검색" + 히어로 "구단주명 입력")임. 어디 쳐야 되는지 0.5초 멈춤. 하나 지워.

**매일 쓸지:** **주 1회**지만 매일에 가까워짐. 매치 리포트 "6:2 승리 · 4골 차 대승" + POTM 9.7 + "이 경기 스토리로 자랑"은 이긴 날 밤마다 열 것. 진 날은 안 염 — 진 판 화면에서 "이거 때문에 졌다" 한 줄이 없음.

**폼 티어 반응:** "폼 골드 40" 개념 자체는 좋음. 챔스 찍었던 사람이 지금 골드면 찔리긴 하는데 그게 현실이라 인정. 문제는 **"40"이 뭔지 모름**. 골드 안에서 40점인지, 상위 40%인지. 롤처럼 "골드 2 · 40LP"나 "다음 플래까지 12"면 바로 앎. 그리고 **카드에선 숫자 없이 "폼 골드"만** 나오고 VS 표에선 "골드 40 vs 골드 44" — 같은 골드끼리 붙여 놓으니 비교 맛이 약함.

**VS 반응:** 이번 개편 최고. 단톡에 "정12의축구교실 근소 우세" 뜨면 바로 싸움 남. 근데 **"1 : 3 항목 승"이 경기 스코어처럼 보임**. 처음엔 "내가 걔한테 1:3으로 졌다고?" 했음. 그리고 2.6 vs 2.6 동점 줄은 왜 셈에 없는지 표시가 없음(0.5로 셀지, 무로 셀지).

**커뮤니티 글쓰기 의향:** 배틀은 투표만 함. 글은 안 씀 — 내 전적 카드를 글에 바로 붙이는 버튼이 없음. 글쓰기 하단 툴바는 "스쿼드 / 양식"뿐.

**문구 톤:** "반등 준비 중", "근소 우세", "너도 친구랑 붙어 봐" 다 좋음. 저번에 말한 거 거의 다 들어줌.

**공유할 화면:** VS 카드(`v2/card-vs.png`), 매치 리포트 대승 화면.

**가장 거슬리는 것 1개:** 홈 검색창 2개.

## B. 서윤 (22, 인스타 라이트) — 7/10

**첫인상 10초:** 색이 드디어 하나가 됨. 아이콘 S 그라데이션이랑 버튼 그라데이션이 같아서 "앱 하나"로 보임. 다크 남보라 + 핑크 CTA는 인스타 감성 맞음.

**매일 쓸지:** **주 1회.** 친구랑 1on1 한 주말에 VS 한 번 + 스토리 한 번. 매일 열 이유는 아직 없음.

**폼 티어 반응:** 동전 아이콘 + "폼 골드" 알약 귀여움. 근데 카드 아래 작은 글씨 "폼 티어는 FC Scope가 최근 경기로 계산한 등급이에요 · 넥슨 공식 등급 아님" — 스토리엔 이 줄이 너무 작아서 아무도 안 읽음. 상관없긴 함.

**VS 반응:** "너도 친구랑 붙어 봐 →" 문구 좋음. 표 6줄은 나한테 약간 많음. 맨 위 "근소 우세" 노란 배지 하나만 있어도 올림.

**MY TYPE 혼란:** 전적 화면은 **"리빌딩 시즌"**, 전적 카드는 **"압박 사냥꾼"**, 같은 카드에 **"안정적인 폼"**인데 화면은 승률 30%에 "반등 준비 중". 내가 뭐라는 거임? MBTI처럼 하나만 있어야 남한테 "나 ○○래" 하고 말함.

**커뮤니티 — 운영자 요구 판정:**
- 글자 크기 작게 → **만족.** 목록 제목이 커뮤니티 앱(에펨·더쿠) 수준으로 줄었고 한 화면에 6~8줄 들어감.
- 목록은 제목만 → **거의 만족.** 말머리 칩 + 제목 + [댓글수] 한 줄, 아래 메타 한 줄. 깔끔. 단 **메타 줄의 조회수·추천이 다시 붙어서**(레거시 목록은 작성자·시간만) 회색 숫자가 많아짐. "추천 61"만 오렌지 강조하는 건 좋음.
- 상세·댓글 보기 좋게 → **반쯤.** 본문 줄간격·예산/포메이션 박스는 예쁨. 근데 **본문 끝나고 광고가 댓글 앞을 막음** — 상세 첫 화면에 댓글이 하나도 안 보임. 댓글 보려고 광고를 지나가야 함.
- 라이트모드도 깨진 데 없이 잘 나옴.

**글쓰기 의향:** "자랑" 말머리로 스쿼드 자랑은 할 듯. 빈 상태 "아직 대회 글이 없어요 · 규칙·일정만 적으면 끝!" 문구 친절함.

**문구 톤:** '~해요' + 가끔 반말 카드 문구, 딱 좋음.

**공유할 화면:** VS 카드, 매치 대승 카드. 전적 카드는 "압박 사냥꾼"이 크게 나오면 올림.

**가장 거슬리는 것 1개:** 내 타입 이름이 화면마다 다름.

## C. 도현 (27, 데이터 덕후) — 5.5/10

**첫인상 10초:** 몰수 포함/제외 라벨 붙인 건 인정. "최근 30 vs 30경기", "2026-10-03 스냅샷" 표기도 좋음. 그런데 커뮤니티에서 새 숫자 불일치가 나옴.

**신뢰 깨는 것 (캡처 근거):**
1. **댓글 수 불일치.** 목록 "도르트문트 팀컬러… **[12]**" → 상세 "댓글 **11**". 배틀 글 목록 **[47]** → 상세 "댓글 **1**". 47 vs 1은 변명 불가. 답글 포함 여부든 캐시든, 같은 숫자로 맞추거나 기준을 써라.
2. **같은 글 2번 노출.** `list-dark.png` 클럽·대회 > 대회 필터에서 "10월 3주차 FC Scope 컵" 행이 **똑같이 두 줄**. 페이지네이션/중복 제거 버그로 보임.
3. **"안정적인 폼"(카드) vs 승률 30%·"반등 준비 중"(화면).** 같은 최근 10경기(4승 2무 4패)를 두고 카드는 안정, 화면은 반등 필요. 산식이 다르면 이름을 바꿔야 함.
4. **폼 티어 산식 비공개.** "골드 40/44"가 몇 점 만점이고 어떤 지표 가중인지 ⓘ가 안 보임. "넥슨 공식 아님"은 썼는데 "그럼 뭐냐"가 없음. 스코어 4.3/10도 여전히 블랙박스.
5. **매치 리포트 "7 / 5 유효슛"** — 위 칸 "7 / 8 슛(나/상대)"과 같은 형식이면 상대 유효슛 5는 맞지만, 라벨에 (나/상대)가 빠져서 헷갈림. 숏맵 범례는 **상대가 왼쪽, 나가 오른쪽**으로 헤더(나 왼쪽)와 반대.

**VS 반응:** 플레이스타일 줄까지 붙인 구성 좋음. 그러나 "항목 승" 계산에서 동점(실점 2.6=2.6) 처리 규칙과 FC 스코어와 승률이 중복 가중되는 문제(둘 다 승률에서 나옴)가 보임. 6개 항목 중 독립 지표가 몇 개냐는 질문 나옴.

**커뮤니티:** 첨부 스쿼드 썸네일이 **초록 박스에 흰 점 11개** — 선수 얼굴·카드 시즌이 하나도 안 보여서 들어가 보기 전엔 정보 0. 평가 요청 글이면 썸네일에 OVR/주요 3명이라도. 1단 답글 + "답글 3개 더 보기" + BEST 고정은 디시·에펨 문법 그대로라 좋음. "제안 스쿼드 보기" 칩(댓글에 스쿼드 첨부)은 이 앱만의 것 — 이건 열광.

**글쓰기 의향:** 픽 랭킹 캡처를 글에 첨부할 수 있으면 매주 "이번 주 메타" 글 씀. 지금 툴바엔 스쿼드만.

**공유할 화면:** 픽 랭킹(여전히 최고 콘텐츠), 제안 스쿼드 달린 댓글 스레드.

**가장 거슬리는 것 1개:** 배틀 글 댓글 [47] vs 1.

## 합의 판정

### 종합: **수정 후 출시**
톤·색·VS는 확실히 좋아졌고 지난번 TOP 3 중 2개(문구, 색 통일)는 해결. 남은 문제는 다시 **숫자 신뢰**(커뮤니티로 옮겨옴)와 **화면마다 다른 내 타입 이름**. 둘 다 덕후 한 명이 캡처해서 올리면 끝나는 종류.

### 운영자 요구(커뮤니티) 판정
| 요구 | 판정 | 비고 |
|---|---|---|
| 글자 크기 작게 | **만족 (3/3)** | 목록·댓글 모두 커뮤니티 앱 밀도. 더 줄일 필요 없음 |
| 목록은 제목만 | **만족 (3/3), 단 메타 줄 정리** | 조회수까지는 과함 — B는 빼라, C는 남겨라. 절충: 조회는 빼고 추천만 |
| 상세·댓글 보기 좋게 | **부분 만족 (A·C 만족, B 불만)** | 본문↔댓글 사이 광고가 첫 화면 댓글을 가림. 배틀 상세는 광고 슬롯이 **빈 박스**로 남음(`battle-dark.png`) |

### 누구를 위한 앱인가
- **B(인스타)** — 1순위로 올라옴. 색 통일 + VS 카드 + 스토리 버튼.
- **A(빡겜러)** — 폼 티어·VS로 처음 진입권. "진 판 이유 한 줄"이 오면 매일 사용자.
- **C(덕후)** — 픽 랭킹·제안 스쿼드로 남아 있지만 숫자 불일치에 가장 먼저 이탈.

### 반드시 고쳐야 할 것 (우선순위)
1. **커뮤니티 숫자·중복 버그** — 목록 [댓글수]와 상세 "댓글 N" 일치(배틀 47 vs 1, 평가 12 vs 11), 대회 필터 같은 글 2회 노출 제거. 답글 포함 여부를 한 기준으로.
2. **"내 타입" 하나로 통일** — "리빌딩 시즌"(MY TYPE) / "압박 사냥꾼"(PLAYSTYLE) / "안정적인 폼"(카드)이 한 계정에 셋. 이름 체계를 정리하고, 승률 30%에 "안정적인 폼" 같은 모순 문구 제거.
3. **폼 티어 "40"과 VS "1:3"의 의미 표시** — 폼 티어에 ⓘ(산식·만점·다음 단계까지), VS 점수는 "항목 1 : 3"처럼 경기 스코어와 구분, 동점 처리 규칙 표기.
4. **상세 화면 광고 위치** — 본문 바로 아래 광고를 댓글 첫 묶음(BEST) 뒤로 내리고, 광고 미로드 시 빈 박스 접기.
5. **홈 검색창 하나로** — 상단 검색바와 히어로 입력창 중복 제거.
6. **계급 카드 2020년 날짜** — 여전히 메인. "커리어 하이" 라벨로 작게 내리거나 폼 티어를 카드 상단에.

(번외: 첨부 스쿼드 썸네일에 핵심 선수 3명, 글쓰기 툴바에 "내 전적/VS 카드 첨부", 숏맵 범례 좌우를 헤더와 일치, `.xyz` 도메인 인상 — 지난번과 동일 지적)
