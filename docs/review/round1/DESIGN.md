## 0. 총평

**판정: 조건부 통과. 이번 라운드에 FIX 10건을 반영하고 다시 캡처해야 한다.**

방향은 맞았다. 라임을 걷어내고 인디고·바이올렛 바탕에 S-spot 그라디언트를 CTA에만 쓴 결과, 아이콘과 앱이 처음으로 같은 브랜드로 보인다. 아이콘의 오렌지→마젠타→바이올렛, 탭 바 선택색 마젠타, CTA 그라디언트가 한 줄로 이어진다. 커뮤니티는 운영자가 요청한 네 가지를 다 해냈다. 목록은 제목 한 줄이고 15pt Medium이라 한 화면에 3개 보이던 글이 9~10개 보인다. 상세 본문은 16/26으로 편하게 읽힌다. 댓글도 상자를 걷어냈다.

토스·스레드 기준에 못 미치는 이유는 큰 구조가 아니라 마감 품질이다.
1. **같은 역할인데 화면마다 크기가 다르다.** 커뮤니티는 `cmText`(보정 없음)를, 나머지 화면은 `fcFont`(×1.15)를 쓴다. 그래서 같은 15pt 탭이 15pt와 17.3pt로 렌더된다.
2. **탭 밑줄이 두 종류다.** 커뮤니티는 ink 단색, 전적은 그라디언트다.
3. **의미 색 규칙이 일부 화면에서 무너졌다.** 상대 팀을 패배 빨강으로, 상대가 앞선 수치를 승리 초록으로 칠했다.
4. **회색·갈색 덩어리.** BEST 띠, 빈 광고 박스, 탁한 MY TYPE 띠가 여기에 해당한다.
5. **중복.** 홈에 검색창이 둘이다. 상세에서는 말머리가 내비 제목과 태그에 두 번 나온다. BEST 댓글은 한 화면 안에 두 번 보인다.

## 3. Must-fix (순위순)

**M1. 타이포 스케일을 하나로 — "같은 역할 = 같은 렌더 크기"**
- 현재: `Theme.swift:90 readable()`은 20pt 미만을 ×1.15 한다. 커뮤니티 `cmText`만 이를 우회한다. 결과적으로 1차 탭이 커뮤니티 15pt, 전적(`RecordHeader.swift:288` `fcFont(15)`) 17.3pt다. 탭 바를 오갈 때 글자가 커졌다 작아진다.
- 변경: 렌더 기준 역할 토큰(`screenTitle 24B / tab 15SB / chip 13SB / body 16 / meta 12 …`)을 `Theme.swift`로 올려 전 화면 공용으로 쓴다. 1차로 **탭·칩·섹션 라벨·리스트 메타**만 옮겨도 체감 불일치는 사라진다. 전적 탭 `fcFont(15)` → `fcText(.tab)`(15pt 렌더).

**M2. 댓글 행 밀도 — 목업 수준으로 조인다**
- 현재: 1줄 댓글 한 행이 약 105pt다(목업 80pt). 본문→행동 줄 사이가 약 30pt로 벌어져 있다.
- 변경(`CommentViews.swift`)
  - 행동 줄 시각 높이 28pt. 탭 영역은 `.contentShape(Rectangle().inset(by: -8))`로 44pt를 유지한다.
  - 본문↔행동 간격 4pt, 행 상하 패딩 10/12pt.
  - 하트 0이면 숫자를 숨긴다.

**M3. 댓글 본문 오른쪽 여백 16pt로 고정**
- 현재: `comments-light`·`legacy-detail-dark`에서 "전적 탭"이 화면 끝 6pt까지 붙는다. 같은 글이 `comments-dark`에서는 16pt에서 줄바꿈된다. 빌드나 경로마다 다르다.
- 변경: 행 `.padding(.trailing, 6)` + 본문 `.padding(.trailing, 10)` 조합을 행 전체 `.padding(.horizontal, 16)` 하나로 바꾼다. `⋯` 버튼은 44×44 `.offset(x: 12)`로 빼서 맞춘다. 다시 캡처해 확인할 것.

**M4. BEST 처리 — 색과 중복**
- 색: `FC.gold.opacity(0.12→0.02)` 그라디언트가 인디고 위에서는 탁한 갈색, 라이트에서는 살구색이 된다. "경고"처럼 보이고 낡았다. → **배경 채움을 없애고**, 행 왼쪽 2pt 골드 바 + `BEST` 배지만 둔다. 라이트 배지는 `#A66A00` 채움 대신 **다크·라이트 공통 `#F7C948` 채움 + `#3A2A00` 글자**로 한다(대비 9:1, 두 모드에서 같은 배지).
- 중복 판정: **에펨식 "원래 자리에도 그대로"는 모바일에서는 틀렸다.** 댓글 11개면 BEST 2개와 원본이 한 화면에 같이 보여 버그처럼 읽힌다. → 원래 자리는 **한 줄 접힘**("↑ BEST로 올라간 댓글 · 펼치기", 13pt faint)으로 바꾼다. 답글 스레드는 BEST 쪽에 붙인다. 또 BEST 노출 조건을 "댓글 5개 이상"에서 **"8개 이상 + 추천 5 이상"**으로 올린다.

**M5. 상세 머리 정리**
- 말머리 "스쿼드 평가 요청"이 내비 제목과 태그에 **두 번** 나온다. 게다가 태그는 긴 이름이라 목록의 짧은 태그 "평가"와 다르다. → 내비 제목은 비워 두고, 제목이 스크롤로 사라지면 글 제목을 15pt SemiBold로 띄운다. 머리 태그는 목록과 같은 **짧은 이름**(`PostTypeNames.short`)으로 쓴다.
- 본문 문단 간격: 빈 줄이 26pt 줄 높이 그대로 들어가 약 26pt가 벌어진다. → `\n\n`으로 나눠 문단 사이 10pt.
- 첨부 스쿼드 썸네일의 채도 높은 초록(#1E6B35)은 팔레트 밖이다. → 스쿼드 빌더 피치와 같은 `#16302A` 계열 + 점 `FC.ink` 80%로 맞춘다.

**M6. 탭·선택 컨트롤 문법 통일**
- 지금 선택 UI가 4종이다. 커뮤니티 ink 밑줄, 전적 **그라디언트 밑줄**(`RecordHeader.swift:291`), 픽 랭킹 시스템 세그먼트, 전적 `공식경기` **흰(다크)/검정(라이트) 채움 알약**.
- 변경
  - 1차 탭 밑줄은 **전 화면 `FC.ink` 2.5pt**로 한다(그라디언트는 CTA 전용 원칙).
  - 모드 드롭다운 알약은 `FC.surface2` 채움 + `FC.ink` 13SB + chevron으로 바꾼다. 지금 화면에서 가장 센 요소가 필터 칩인 것은 위계 오류다.
  - 픽 랭킹 세그먼트는 커뮤니티 2차 칩 스타일(32pt 캡슐, 선택 시 tint 12% + 1.5pt tint 테두리)로 바꾼다.

**M7. 빈 광고 박스와 첫 화면 광고**
- `battle-dark`: 로드 전 `AD · 광고` 빈 surface 박스가 150pt를 차지한다. → `expectedHeight` 예약은 첫 화면 아래에서만 하고, 첫 화면 안에서는 0 높이로 시작한다. 로드되면 `.transition(.opacity)`로 나타나게 한다(감사 #1 원칙).
- 커뮤니티 목록·상세는 아직 320×100이다. 목록에서는 첫 화면의 18%를 쓴다. SPEC 5절의 행 높이 네이티브 또는 320×50 적응형은 운영자 결정 사항이다. 이번에 결정을 받을 것.

**M8. 전적 헤더 다이어트(첫 화면에 경기 1줄은 보이게)**
- 덜어낼 것
  - `승률은 몰수 7경기 포함 · 빼면 35%` 각주 → 승률 타일 안 `ⓘ` 팝오버로.
  - MY TYPE 오른쪽 설명 3줄 → **최대 2줄, 12pt, `lineLimit(2)`**.
  - `친구랑 비교 (VS)` 풀폭 행 → CTA 줄 오른쪽 44pt 원형 보조 버튼(`person.2`)이나 내비 우측 메뉴로.
  - `내 구단으로` 카드 모서리 링크 → 내비 ★ 옆 메뉴 또는 이름 줄 오른쪽 정렬(기준선 맞춤).
- MY TYPE 띠 다크 배경(적갈색)은 탁하다. → `FC.surface2` + 왼쪽 3pt 브랜드 그라디언트 바로 바꿔 매치 히어로·공유 카드와 같은 문법으로 맞춘다.

**M9. 의미 색 규칙 복구 — "상대 = 중립"**
- 매치 점유율 바, 슛맵 상대 점, 매치 공유 카드 상대 슛 라벨이 `lose` 빨강이다. → **나 = `FC.tint`, 상대 = `FC.muted`(다크 #A6A2C8 / 라이트 #5E5A78)**. 빨강·초록은 결과(승·패)와 좋고 나쁨에만 쓴다.
- VS 표에서는 앞선 쪽을 무조건 `win` 초록으로 칠한다. → 앞선 값은 `FC.ink` Bold + 값 옆 `FC.tint` 6pt 점, 뒤진 값은 `FC.muted` Regular. 초록·빨강은 쓰지 않는다. `◂ ▸` 화살표는 없앤다. VS 공유 카드(▲)도 같은 규칙으로 맞춘다.
- 매치 카드 `무승부 / 3:3 난타전 무승부` → 큰 라벨 `무승부` + 보조 `난타전`(반복 제거).

**M10. 탭 바 뒤에 깔리는 CTA**

**M11. 홈 — 검색창 1개, 브랜드 1번**
- 내비 `.searchable`(`HomeView.swift:57`)과 히어로 입력이 같은 일을 한다. → 홈에서는 `.searchable`을 없애고 히어로 필드에 포커스되면 최근 검색 제안을 그 아래 드롭다운으로 보여 준다. 또는 `.searchable`을 히어로가 화면 밖으로 나갔을 때만 노출한다.
