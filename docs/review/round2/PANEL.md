## A. 준서 (18, 랭겜 빡겜러) — 7.5/10

**첫인상 10초:** 검색창 하나. 됐음. "나 요즘 왜 지는지, 30경기로 바로 진단" → 바로 닉 침. 머무를 이유 충분함.

**재방문: 주 1회 (이긴 날은 매일).** 4:2 승리 "안정감 있게 챙긴" + POTM 8.7 + "이 경기 스토리로 자랑"은 이긴 밤마다 염. 근데 **1:4 패배 화면은 "패배 · 오늘은 좀 꼬였던 판"이 끝**. 꼬였다는 건 나도 앎. 상대 유효슛 8개 중 4골, 내 슛 2개 — "슛 2개로는 못 이김, 박스 진입이 막혔음" 같은 이유 한 줄이 없으니 진 날은 안 열고, 그래서 매일 앱이 못 됨. 1라운드에서 한 말 그대로임.

**공유:** VS 카드 "보엠 압승 5 : 0 이긴 항목" — 단톡에 바로 올림. 1라운드의 "1:3 스코어처럼 보임" 문제는 "이긴 항목" 라벨로 해결. 폼 골드 44점 ⓘ도 이제 뭔지 앎.

**가장 거슬리는 것:** 진 판 화면에 "왜 졌는지"가 없음. 위로 문구 말고 원인을 줘.

## C. 도현 (27, 데이터 덕후) — 7/10

**첫인상 10초:** 리포트 "24경기 득실 · 몰수 제외 71 : 64", 경기당 3.0 / 실점 2.7과 산수 맞음(71/24, 64/24). "최근 7일 승률 40%"도 "이번 주 25판 10승 4무 11패"와 맞음. 픽 랭킹 "2026-10-03 스냅샷"도 유지. 숫자 기준 정리는 인정.

**재방문: 주 1회.** 픽 랭킹 갱신 확인용. 매일 올 콘텐츠는 아직 없음.

**신뢰를 깨는 것 (근거):**
1. **댓글 [12] vs 11이 아직 살아 있다.** 목록 `도르트문트… [12]` → 상세 `댓글 11`. 앱이 상세를 열어 본 뒤에만 목록을 11로 고치고, 그것도 실행 중에만 기억한다. 처음 보는 유저와 재실행한 유저는 무조건 어긋남을 본다. 서버 `comment_count`가 숨김 댓글을 빼고 세게 고쳐야 끝난다. 이건 클라이언트 땜질이다.
2. **전적 카드 기준이 섞여 있다.** 카드 상단은 "최근 30경기 · 몰수 6 포함"(11승 5무 14패, 37%)인데 아래 "경기당 득점 3.0 / 총 득점 71"은 몰수 제외 24경기 기준. 71/30 = 2.37이다. 화면 리포트에는 "몰수 제외" 라벨이 있는데 카드에는 없다. 캡처해서 올리면 바로 지적당한다.
3. **몰수승 표시가 안 보인다.** 최근 10 스트립 두 번째 "승"이 점선 테두리(몰수)인데, 초록 타일 위의 점선이라 확대해야 보인다. 몰수패(붉은 타일)는 잘 보이는 것과 비대칭.
4. 픽 랭킹 "37회"의 분모(몇 경기·몇 명 랭커 중)가 없다. 산식 공개 측면에서 아쉬움. 감점은 작음.

**좋은 것:** 폼 티어 산식 시트, VS 동점 수 표기 규칙, 슛맵 점 개수 = 슛 수, 골 = 채운 점. 제안 스쿼드 댓글 + BEST + 답글 접기 구조는 여전히 이 앱만의 무기.

**가장 거슬리는 것:** 댓글 [12] vs 11 — 1라운드 1순위였는데 서버는 그대로고 화면에서만 가렸다.

## 합의 판정

### 종합: **수정 후 출시** (1라운드와 같지만 남은 항목이 6개 → 2개 필수로 줄었음)

### 반드시 고칠 것 (우선순위)
1. **댓글 수를 서버에서 맞추기** — `comment_count` 트리거가 숨김(hidden) 댓글을 빼고 세도록(웹 저장소 마이그레이션). 앱의 `noteCommentGap`은 보조로만 남긴다. 처음 보는 목록에서 [12] → 11이 나오면 안 됨.
2. **전적 카드 득점 기준 표기** — 카드 "몰수 6 포함" 헤더 아래에 득점 3.0 / 71(몰수 제외 24경기)이 섞여 있음. "득점 · 몰수 제외 24경기" 라벨을 달거나, 카드 전체를 한 기준으로.

### 권장 (승인 점수에 영향)
3. **패배 매치 리포트에 원인 한 줄** — "오늘은 좀 꼬였던 판" 대신 슛·유효슛·점유 차이로 만든 진단 1줄. A를 매일 사용자로 만들 유일한 항목.
4. 몰수승 표시를 초록 타일 위에서도 보이게(점선 대비 강화 또는 작은 "몰" 표시).
5. 글쓰기 툴바에 "내 전적 카드 / VS 카드 첨부"(2라운드 연속 지적).

### 누구를 위한 앱인가
- **B(인스타)** — 8점. 지금 상태로 바로 쓸 사람. VS·전적 카드 공유가 핵심.
- **A(빡겜러)** — 진입 장벽은 모두 해소됨. 진 판의 이유 한 줄이 오면 8점 이상.
- **C(덕후)** — 숫자 기준 정리는 크게 개선됨. 댓글 수 서버 수정 + 카드 기준 라벨이면 8점.

### 승인 조건
필수 1·2와 권장 3을 반영하면 3인 모두 8점 이상이 예상된다. **이번 라운드는 패널 승인 아님.**
