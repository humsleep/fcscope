# R1 → R2 에서 고친 것
- 숫자 이름 정리: FC 스코어 → "경기력"(10점 만점), 넥슨 매치 평점 → "넥슨 평점". 경기 목록 행에는 경기력 숫자 하나만.
- 폼 티어 옆 "보통 = 플래티넘" → "평균보다 한 단계 아래"처럼 평균 대비 말로.
- 전적 첫 화면: 푸시 권유 카드와 광고를 경기 목록·진단 뒤로 내림.
- 홈: 마지막 경기 카드(슛맵·POTM) 추가, 광고는 받기 전엔 자리를 잡지 않음(빈 회색 상자 제거).
- 몰수 칩: 빨강 "몰수" → 중립색 "몰수 경기".
- 매치 리포트 POTM: "경기 최우수 선수 · 우리 팀/상대 팀"으로 풀어 씀.
- 온보딩 페이지 전환을 직접 그리도록 바꿈(실행 직후 탭하면 점·버튼과 내용이 어긋나던 버그).
- 내 정보 로그인 버튼 문구 "Apple · Google로 로그인" → "로그인"(실제 시트는 표준 Apple 버튼).
