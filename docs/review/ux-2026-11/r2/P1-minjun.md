## 현재 P0/P1 (P0 없음, P1 6개)

1. **[P1·잔존] 10점 척도 숫자가 세 개** (06, 07b, 13)
   - 고칠 방법: 앱 전체에서 경기력 하나만 쓴다. 넥슨 평점은 매치 리포트 안에서만 보여 준다. 경기력 옆에 ⓘ를 달고 "무엇으로 계산하는지"를 한 줄로 쓴다. 폼 등급은 금속 이름 대신 디비전 내 백분위로 바꾼다.
2. **[P1·신규] 매치 리포트 중간의 300x250 광고** (11)
   - 문제: 숏맵과 팀 스탯 사이에 끼어서, 원인을 찾는 흐름의 한가운데를 끊는다.
   - 고칠 방법: 광고를 선수 평점 아래, 즉 리포트 맨 끝으로 옮기고 배너 크기로 줄인다.
3. **[P1·잔존] 몰수 경기 처리** (06, 07, 07b)
   - 고칠 방법: 기본값은 승률·득실·경기력 평균에서 몰수를 빼고 "몰수 포함" 토글을 둔다. 몰수 행에서는 점유율과 경기력을 숨긴다.
4. **[P1·신규] 유효슛 수치가 정확한지 의심됨** (07b, 10, 12, 13)
   - 문제: 본 두 경기 모두 내 슛이 전부 유효슛이다(8/8, 7/7). 그런데 홈 카드에서는 상대 쪽 유효슛 수가 아예 빠져 있다.
   - 고칠 방법: 데이터센터와 3경기 이상 대조해서 매핑을 확인한다. 홈 카드에도 양 팀 유효슛을 같은 형식으로 표시한다.
5. **[P1·잔존] 피온북 대비 기본 정보 부족** (06, 12, 14)
   - 고칠 방법: 헤더에 현재 디비전과 포인트를 넣는다. 매치 리포트 선수 행에 시즌 배지와 +강화를 붙인다. 시세는 선수 상세 화면 안에서 보여 준다.
6. **[P1·잔존] 내용이 빈 영역** (08, 16)
   - 고칠 방법: 진단 문구는 비교 기준이 있는 수치로 바꾼다. 커뮤니티는 실제 글이 쌓일 때까지 숨기거나 메타 콘텐츠로 채운다.

## 3일 뒤에도 남겨 둘까?
**아니오.** 홈의 마지막 경기 카드는 나아졌지만, 데이터는 여전히 피온북보다 적고, 몰수 처리와 유효슛처럼 정확성이 의심되는 부분은 하나도 손대지 않았다.
