## 3. 새로 보이거나 남은 P0/P1

### P1
1. **매치 리포트 한가운데에 큰 광고가 있음** — `11`
   - 슛맵을 보고 내리면 팀 스탯 전에 화면 절반 크기 광고가 나와서 흐름이 끊김. 진 이유를 보러 들어온 화면인데.
   - 고칠 방법: 리포트 맨 아래 "보엠 전적으로" 위로 옮기고, 크기를 320x100으로 줄이기.
2. **경기력이 정작 경기 리포트에 없음** — `07b`, `10`
   - 목록에는 "3.3 경기력", 리포트에는 "6.5 넥슨 평점"만 있음. 홈 카드(13)에는 넥슨 평점 7.3에 선수 평점 9.8까지 나옴. 숫자가 셋인데 어떤 게 진짜 내 점수인지 모르겠음.
   - 고칠 방법: 리포트 상단 칸 하나를 "경기력 3.3 / 10"으로 바꾸고, 넥슨 평점은 아래로 내리기. 왜 3.3인지(실점·유효슛 등)도 한 줄로 보여주기.
3. **같은 걸 화면마다 다르게 부름** — `06`, `07b`, `13` ↔ `10`
   - 리포트는 "경기 최우수 선수"인데 홈·전적 카드는 아직 "POTM"이라고 씀. "선수 평점"과 "넥슨 평점"도 섞여 있음.
   - 고칠 방법: 모든 화면에서 "경기 최우수 선수"로 통일하기. 평점 이름도 하나로 정하기.
4. **몰수 경기에 경기력 점수가 붙어 있음** — `07`, `07b`
   - 안 뛴 경기 같은데 패는 3.0, 승은 6.0이 붙어 있음. 내 경기력 4.6이 억울하게 낮은 것 같음.
   - 고칠 방법: 몰수 경기는 점수 대신 "—"를 표시하고 평균에서 빼기. 칩을 누르면 "상대나 내가 나가서 0:3 처리"라고 설명하기.
5. **홈 슛맵에 범례가 없음** — `13`
   - 파란 점이 왼쪽 골대에 몰려 있는데, 이게 내가 찬 건지 먹힌 건지 모르겠음. 채운 점과 빈 점의 차이도 모르겠음. 범례(● 골 · ○ 노골)는 리포트(11)에만 있음.
   - 고칠 방법: 홈 카드 슛맵 아래에도 "● 골 ○ 노골, 내 슛은 →방향" 한 줄 달기.
6. **용어 설명이 여전히 없음** — `07b`, `10`, `12`, `14`
   - 고칠 방법: R1과 같음. 처음 나올 때 괄호로 풀어 쓰기(유효슛=골문으로 간 슛, A=어시스트), 배지 범례 달기.
