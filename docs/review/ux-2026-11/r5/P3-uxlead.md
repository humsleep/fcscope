# P3 시니어 모바일 UX 리드 — r5(최종) 재평가

r5 캡처 19장을 모두 봤다. 한 빌드로 첫 설치부터 찍었고, 겹치는 파일은 없다. 승리 리포트(08·09·10·11)와 패배 리포트(13)를 둘 다 봤다. 로그인 시트는 끝까지 캡처되지 않았다. 수치는 393pt 폭 기준 추정치다.

칭찬 한 줄: 경기력 근거 팝오버(09, 6.5 + 1.05 + 0.49 + 0.06 = 8.1)는 이 장르에서 보기 드문 투명성이다. 숫자가 이제 전 화면에서 일관된다(06·07·14 모두 8.1).

## 3. 남은 P0/P1 (6개, 중요도순)

**1. [미해결 P1] 17 — 스쿼드 첫 화면 하단 겹침**
정지 상태에서도 도움말 문단과 버튼 줄이 반투명 탭바 밑에 겹쳐 보인다.
고칠 방법: 탭바 배경 불투명도를 90% 이상으로 올리거나 탭바 위에 24pt 페이드 마스크를 둔다. 도움말은 피치 위 한 줄(13pt)로 올린다.

**2. [P1] 06·08·13·14 — 시각 문법이 셋 이상**
카드 테두리 5종, 섹션 제목 4방식, 칩 5종이 섞여 있다. 같은 진단 카드도 패배는 회색 라벨 "왜 졌을까", 승리는 초록 라벨 "이렇게 이겼어요"로 다르게 생겼다.
고칠 방법: 아래 4절 참고.

**3. [P1] 01~05 — 첫 30초**
일반 SF Symbol 아이콘 3장이 있고, 빈 공간이 약 40%이며, 진입하자마자 ATT가 뜬다.
고칠 방법: 3쪽에 실제 마지막 경기 카드 미리보기 이미지(높이 약 240pt)를 넣는다. ATT는 첫 리포트를 닫은 뒤로 미룬다.

**4. [부분 P1] 06 — 히어로 밀도**
고칠 방법: "평균보다 한 단계 아래", "몰수 제외", 점선 범례를 ⓘ 시트 안으로 옮긴다. 요소는 8개 이하로 줄이고, 글자 크기는 28/17/13pt 세 단계로 맞춘다.

**5. [부분 P1] 12·15 — 큰 광고와 소재**
고칠 방법: 모두 320×50(컨테이너 약 70pt)으로 바꾼다. 16세 사용자를 고려해 AdMob 최대 광고 콘텐츠 등급을 T로 묶는다(12 테스트 소재에 패션·캐릭터 이미지가 보였다). 배너는 검은 띠 없이 가운데 정렬한다.

**6. [부분 P1] 18 — 운영자 글뿐인 커뮤니티**
고칠 방법: 시드 글은 "가이드" 섹션 하나로 접고, 날짜 "9.21"은 숨긴다. 빈 상태 CTA와 FAB 중 하나만 남긴다.

## 4. 남은 일관성 문제 상위 3개
1. **카드 테두리 5종**: 홈 한 화면에서만 라벤더 → 초록 → 회색 → 초록이 이어진다(14). 기본은 회색 1px·반경 16pt로 두고, 강조 카드 1장에만 초록을 쓴다.
2. **섹션 제목 4방식**: 카드 밖 회색, 카드 안 회색, 초록 라벨, 금색 라벨이 섞여 있다(08·13). 카드 밖 13pt semibold 하나로 통일하고, 진단 카드 두 종류도 같은 모양으로 맞춘다.
3. **칩 5종**: 4색 진단 알약(12), 점선 범례(06), 남색 테두리(16), 아이콘 칩(17), 라벤더 태그(18). 중립 칩 1종과 상태 칩 2색으로 줄인다.

## 5. 피처드 후보인가?
**아니오.** 숫자 체계와 핵심 흐름은 피처드 수준에 가까워졌다. 하지만 시각 문법이 R1부터 거의 바뀌지 않았고, 4라운드째 남아 있는 스쿼드 겹침이 완성도 인상을 깎는다.

## 6. 8점을 넘으려면 꼭 필요한 것 3가지
1. **디자인 토큰 한 벌로 정리**(시각 6 → 8): 카드 2종, 섹션 제목 1종, 칩 2종으로 줄이고 모든 화면에 일괄 적용한다. 스쿼드 겹침도 함께 고친다.
2. **첫 30초 재설계**(첫인상 6 → 8): 온보딩에서 실제 결과를 미리 보여준다. ATT는 첫 리포트 뒤로 미루고, 히어로는 요소 8개 이하로 줄인다.
3. **매일 열 이유 + 광고 절제**(정보 7 → 8, 신뢰 7 → 8): 홈에 매일 바뀌는 정보(폼 변화, 연승·연패, 이번 주 경기력 추이)를 넣는다. 광고는 탭당 1개, 320×50으로 제한한다. 커뮤니티는 실사용자 글이 생길 때까지 축소한다.
