## 3. 남은 P0/P1 (P0 없음)

1. **P1 전적 목록 광고가 크고, 소재가 16살한테 부적절해 보임** — `12`
   - 경기 목록 바로 아래 큰 사진 광고에 몸매 강조 옷이랑 애니 여자 그림이 나옴. 친구 옆에서 열기 민망함. 홈(15)·리포트(11)는 작은 배너인데 여기만 큼.
   - 고칠 방법: 전적 광고도 320×50으로 고정하고, 미리 받아 둔 옛날 크기 광고는 버리기. 광고 SDK에서 콘텐츠 최대 등급을 G 또는 PG로 낮추기(청소년 사용자가 많은 앱). 광고 위치는 진단 카드 아래로 옮기기.
2. **P1 시즌 배지 10종이 설명 없이 늘어남** — `11`, `16`
   - 선수 이름 앞 작은 네모(26TS, SPT, DCB…)가 뭔지 하나도 모르겠음. 오히려 더 복잡해짐.
   - 고칠 방법: 배지를 누르면 "26TS = 26 팀 오브 더 시즌" 같은 시즌 이름 시트가 뜨게 하기. 아니면 리포트에서는 배지를 빼고 선수 상세에서만 보여주기.
3. **P1 첫 화면 큰 버튼 3개 중 2개가 뭔지 모름** — `06`
   - "계급"과 "VS"는 5라운드 내내 뭔지 몰랐음. 누르기 전에는 알 수가 없음.
   - 고칠 방법: 버튼 이름을 "계급표 보기", "친구랑 비교"로 바꾸기. 또는 버튼 아래 작은 글씨로 한 줄 설명 달기.
4. **P1 커뮤니티는 아직 살아 있지 않음** — `18`
   - 빈 화면 안내는 좋아졌는데, 두 달 전 운영자 글 4개가 전부임.
   - 고칠 방법: 운영자 글은 "공지·예시"로 묶어서 접기. "인기" 탭은 글이 쌓이기 전까지 숨기기. 매치 리포트에서 바로 "이 경기 평가받기"로 글을 쓸 수 있게 연결하기.

### P2
- `07` 승률 설명이 경기력 ⓘ 안에 숨어 있음. 승률을 궁금해하는 사람은 거기서 못 찾음.
- `12` "5할 돌파"는 아직 그대로.
- `10` 드리블 84/81은 단위가 없음.

## 6. 8점을 넘으려면 꼭 필요한 것 3가지
1. **광고 정리:** 모든 화면 320×50으로 통일하고, 목록 중간이 아니라 맨 아래에 두기. 광고 콘텐츠 등급은 G/PG로 제한하기.
2. **용어 도움말 한 곳:** 유효슛, 포지션 약어, 시즌 배지, 계급, 폼 티어를 누르면 같은 모양의 설명 시트가 뜨게 하기. 처음 볼 때 한 번 반짝여서 누를 수 있다는 걸 알려주기.
3. **첫 30초 정리:** 계급·VS 버튼에 뜻이 보이는 이름 붙이기. 추적 팝업 전에 "광고를 덜 이상하게 보여주려는 것" 한 줄 안내(앱 자체 화면) 넣기. 첫 방문 헤더는 승률·경기력·최근10만 보여주기.
