### R6 에서 남은 지적(디자인)
- 강조 테두리 남발(홈 4장 중 3장) — 화면당 1장으로.

- 스쿼드 "저장·공유 링크" 줄이 탭바에 잘림 — 하단 여백 약 110pt.
- 이긴 경기 진단이 칭찬만 함(슛 4:7로 밀렸는데 "점유율로 주도") — 상대가 앞선 지표면 위험 요소 한 줄.

- 통과선 8.0은 셋 다 미달.

## 크게 나아진 것
- 숫자 체계: "경기력"(누르면 계산 근거)·"넥슨 평점" 두 개로 정리, 목록·홈·리포트가 같은 숫자.
- 경기 리포트 흐름: 전적 → 승/패 리포트 → 원인(이렇게 이겼어요 / 왜 졌을까) → 근거 → 공유가 끊김 없이 이어짐(P3: "이 장르에서 보기 드문 강점").
- 신뢰: 몰수 경기 표기·기준 공개, 리포트 중간 광고·스쿼드·내 정보 광고 제거, NEW 남발 제거.
- 버그: 온보딩 페이지 어긋남, 시즌 배지 미표시.

## 8점을 넘으려면 (패널 공통)

### 디자인으로 풀 수 있는 것
1. **시각 문법 통일**: 카드 테두리 5종 → 2종, 섹션 제목 4방식 → 1, 칩 5종 → 2. 승/패 진단 카드 모양 통일. (P3 1순위)
2. **첫 30초**: 온보딩에 실제 경기 카드 미리보기, 헤더 요소 8개 이하, "계급"·"VS" → "계급표 보기"·"친구랑 비교", 승률 아래 "몰수 빼면 48%" 상시 노출.
3. **광고 절제**: 전 화면 320×50 고정(전적·홈 슬롯은 미리 받기 때문에 큰 소재가 남음), 광고 콘텐츠 등급 제한(16세 사용자), 스쿼드 첫 화면 탭바 겹침.
4. **용어 도움말 한 곳**: 유효슛·포지션 약어·시즌 배지·폼 티어.

### 데이터·제품 결정이 필요한 것
1. **경기력 정의**: 지금은 결과 기본값(승 6.5 / 패 3.8)이 대부분이라 "승패를 다시 말하는 숫자"로 읽힘. 결과와 무관한 경기 내용 지표로 재정의할지.
2. **매일 열 이유**: 30경기 누적 분석(실점 시간대·위치, 선발 선수 성적표 + 강화, 같은 디비전 평균 비교). 강화(spGrade)는 넥슨 원본에 있어 서버 매치 API 필드 추가로 가능.
3. **커뮤니티**: 실사용자 글이 생길 때까지 운영자 글을 공지로 접거나 탭을 축소.
