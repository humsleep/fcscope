# R3 → R4 에서 고친 것
- 매치 리포트 히어로 셋째 칸 = 그 경기 "경기력 · 10점 만점"(전적 목록과 같은 숫자). 넥슨 평점은 팀 스탯 표 "넥슨 평점 (선수 평균)" 행으로.
- 마지막 경기 카드 윗줄: "넥슨 평점" → "경기력"(한 카드에 같은 이름 두 숫자 제거). 넥슨 평점은 최우수 선수 줄에만.
- 좋음 색 통일: 선수별 넥슨 평점의 좋음도 초록(금색은 최우수 선수 전용).
- 경기력 ⓘ 설명: 불투명 배경 · 본문 크기로 키움 · 몰수 경기를 평균에 어떻게 넣는지 밝힘.
- 헤더 실점 옆에 "몰수 제외"(몰수가 있을 때) — 득점·실점은 원래 몰수를 뺀 값이었다.
- 몰수 문구 중립화: "몰수 · 한쪽 이탈·끊김"(내가 진 몰수에도 맞게).
- 슛맵 범례 풀어 씀: 왼쪽 골대 = 내가 공격 · 채운 점 골 · 빈 점 노골 · 금색 테두리 골대 맞힘.
- 선수별 평점: "⚽1 A1" → "1골 1도움". 급상승 "▲8" → "선발 +8". 선수 탭: 모든 행이 NEW면 표시 안 함(일부만 새로면 "새로").
- 진단 문구의 " — " 대시 → 쉼표.
- 광고 줄임: 스쿼드 빌더 광고 제거, 내 정보 쿠팡 배너 제거, 커뮤니티는 글 8개 미만이면 목록 광고 없음.
- 온보딩: 상단 로고 워드마크, 내용 위치를 조금 위로.
- 05: 온보딩 직후 전적 화면 위 추적 동의(ATT) 팝업 — 심사 요건이라 이 시점에 뜬다(의도).
