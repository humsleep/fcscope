## 현재 P0/P1 (P0 없음, P1 6개)

1. **[P1·신규] 마지막 경기 카드의 숫자가 화면마다 바뀜** (06, 07)
   - 문제: 같은 세션, 같은 경기인데 06에서는 `경기력 8.1`, 07에서는 `넥슨 평점 7.3`으로 나온다. 이름과 값이 같이 바뀌니 데이터를 의심하게 된다.
   - 고칠 방법: 카드 부제를 하나의 값에서만 그리게 한다. ⓘ 팝오버를 연 뒤나 다시 그려질 때 옛 문구가 남아 있는지 확인한다.
2. **[P1·잔존] 경기력이 승패를 다시 말할 뿐** (07, 09)
   - 고칠 방법: 승패를 빼고 슛 위치·유효슛·점유·패스를 상대와 비교한 값으로 다시 정의한다. 그래야 "이겼지만 운이 좋았다", "졌지만 잘했다"가 드러난다. 그렇게 못 하면 히어로 칸에서 내리고 넥슨 평점을 쓴다.
3. **[P1·잔존] 선수 시즌·강화 미표시** (11, 12)
   - 고칠 방법: 선수 탭(15)에 이미 있는 시즌 배지를 리포트 선수 행에도 쓰고, +강화 단계를 함께 표시한다.
4. **[P1·잔존] 폼 등급 이름** (06)
   - 고칠 방법: 금속 이름을 빼고 "챔피언스 유저 중 상위 N%"처럼 무엇과 비교하는지 밝힌다.
5. **[P1·잔존] 진단 문구가 운세 수준** (08)
   - 고칠 방법: 근거 없는 문장은 지우고 시간대별 실점, 득점 전환율, 같은 디비전 대비 수치로 바꾼다.
6. **[P1·잔존] 커뮤니티에 사람 없음** (17)
   - 고칠 방법: 실제 글이 쌓일 때까지 탭을 숨기거나 메타·픽 콘텐츠로 채운다. 운영자는 따로 구분되는 계정으로 쓴다.
