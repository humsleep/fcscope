# P3 시니어 모바일 UX 리드 — r4 재평가

r4 캡처 18장을 모두 새로 봤다. 11과 12는 해시는 다르지만 같은 장면이다. 이번 리포트 캡처는 패배가 아니라 **승리 경기**(2:1 vs lleol10)다. 로그인 시트는 이번에도 캡처에 없다. 수치는 393pt 폭 기준 추정치다.

칭찬 한 줄: 경기력과 넥슨 평점의 역할이 화면 전체에서 처음으로 맞아떨어졌다. 리포트 히어로의 7.3이 목록의 7.3과 같고, 좋음 색도 초록 하나로 통일됐다.

## 3. 지금 남은 P0/P1 (최대 6개, 중요도순)

**1. [신규 P1] 06·07·13 — 같은 카드의 라벨과 값이 바뀐다**
같은 회차의 같은 마지막 경기 카드(5:2 준페트루치)가 06과 13에서는 "경기력 8.1", 07에서는 "넥슨 평점 7.3"으로 찍혔다. R2에서도 같은 종류의 뒤집힘이 있었다. 핵심 숫자가 상황에 따라 다르게 보이면 오해를 부른다.
고칠 방법: 카드는 데이터가 확정된 뒤 한 번에 그린다. 확정 전에는 숫자 자리에 회색 스켈레톤(폭 40pt)을 둔다. 캐시 값과 새 값의 라벨 스키마를 하나로 맞춘다.

**2. [신규 P1] 09 — 승리 리포트에는 원인 카드가 없다**
패배 리포트에는 "왜 졌을까"가 있는데, 승리 리포트는 히어로에서 바로 공유 버튼으로 넘어간다. 경기의 절반에서 "원인 파악"이 빠지는 셈이다.
고칠 방법: 같은 자리(히어로 아래 12pt)에 같은 카드 형식으로 "왜 이겼을까" 2~3줄을 넣는다(예: 유효슛 4/4 결정력, 점유 61%).

**3. [재발견 P1] 16 — 스쿼드 탭을 처음 열면 하단 문단이 탭바 밑에 겹쳐 보인다**
16은 스크롤하지 않은 정지 상태인데도 도움말 문단과 버튼 줄이 반투명 탭바 아래에서 겹친다. R3의 "스크롤 중에만 생긴다"는 설명과 다르다. 모든 사용자가 첫 화면에서 보게 된다.
고칠 방법: 탭바 배경 불투명도를 90% 이상으로 올리거나, 탭바 위에 24pt 페이드 마스크를 둔다. 도움말은 피치 위 한 줄(13pt)로 올린다.

**4. [미해결 P1] 17 — 비어 있는 커뮤니티**
고칠 방법: 시드 글은 "가이드" 섹션 하나로 접는다. 빈 영역에는 "첫 스쿼드 평가 받기" CTA 카드를 둔다(높이 약 120pt, 이미지 포함).

**5. [부분 P1] 06 — 히어로 밀도**
고칠 방법: ⓘ는 경기력 하나만 남기고, 승률과 폼 설명은 같은 시트로 합친다. "몰수 제외"는 ⓘ 설명 안으로 넣는다. 최근10 점선 범례는 칩 안의 "몰" 표식으로 바꾼다. 요소 수를 8개 이하로 줄인다.

**6. [부분 P1] 08·12·14·15 — 광고 크기**
고칠 방법: 남은 4곳을 320×50 적응형(컨테이너 약 70pt)으로 바꾼다. 리포트 끝 광고는 "← 보엠 전적으로" 링크와 자리를 바꿔 맨 마지막에 둔다.

### 신규 P2
- 05: ATT가 첫 데이터 화면 위에 바로 뜬다. ATT는 광고 추적을 하기 전에만 띄우면 된다. 첫 리포트를 본 직후로 미루면 거절률과 첫인상이 모두 나아진다.
- 07과 08 사이 몰수 처리가 맞지 않는다. 팝오버는 "몰수승 6 · 몰수패 3으로 평균에 넣는다"고 하는데, 목록 행은 "—"를 보여준다. 행에도 "6.0 고정"처럼 회색으로 표시한다.
- 10: 슛맵 범례 문장을 지도 위쪽의 아이콘 범례(●골 ○노골 ◎골대)로 바꾼다.

## 4. 남은 일관성 문제 상위 3개
1. **카드 테두리 5종**: 홈 한 화면에서 라벤더 → 초록 → 회색 → 초록이 이어진다(13). 기본은 회색 1px로 두고 강조 카드 1장에만 색을 쓴다.
2. **섹션 제목 4방식**: 리포트에 카드 밖 회색 제목("숏맵"·"팀 스탯"·"선수별 넥슨 평점"), 금색 카드 내부 라벨("경기 최우수 선수"), 홈의 남색·초록 라벨이 섞여 있다. 카드 밖 13pt semibold 한 가지로 통일한다.
3. **칩 5종**: 4색 진단 알약(08), 점선 범례(06), 남색 테두리 칩(15), 아이콘 칩(16), 라벤더 태그(17). 중립 칩 1종과 상태 칩 2색으로 줄인다.

## 5. 피처드 후보인가?
**아니오.** 숫자 체계는 이제 믿을 만하다. 하지만 라벨이 바뀌는 카드, 승리 경기의 원인 공백, 첫 화면의 탭바 겹침, R1부터 그대로인 카드·제목·칩 문법이 남아 있다.
