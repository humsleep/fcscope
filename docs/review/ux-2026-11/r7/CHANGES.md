# R6 지적 반영 (2026-11-21)

캡처: 01~03 온보딩, 04 홈, 05~07 전적, 08 패배 리포트, 09~11 승리 리포트(슛맵 범례·선수 평점), 12 두 번째 승리 리포트, 13 스쿼드, 14 내 정보.
01~03은 공용 시뮬레이터, 04~14는 전용 시뮬레이터(FCScope UX Review)에서 찍었다. 07은 그 뒤 수정과 무관한 화면이라 앞 빌드 캡처를 그대로 둔다.

## 고친 것
- **강조 테두리 화면당 1장**: 홈 "내 구단"·급상승, 전적 주간·연승·천적·알림 요청 카드의 강조를 뺐다. 홈·전적에서 초록 테두리는 마지막 경기 카드만(04, 05, 07).
- **헤더 버튼 모양 통일**: "친구 비교"를 "등급 카드"와 같은 회색 채움 + 회색 테두리 + 15 bold로. 주 버튼 1 + 같은 모양 보조 2(05).
- **"계급" → "등급"**: 넥슨 공식 용어(최고 등급)와 맞췄다. 버튼 "등급 카드", 카드 칩 "등급 인증".
- **스쿼드 저장 줄**: 스크롤 끝 대신 탭 바 위에 고정(바탕색 + 위 실선). 흐림 마스크는 뺐다(13).
- **이긴 경기 진단**: 슛이 뒤졌으면 "주도했어요"를 말하지 않는다. 상대가 슛 3개 이상·유효슛·점유 56% 이상으로 앞서면 "다만 …" 위험 줄 1개(빨간 ▸). 이번 데이터의 승리 두 경기는 해당 없음(09, 12).
- **용어 설명**: 리포트 히어로 아래 "유효슛 = 골문 안으로 간 슛(골 포함)"(08, 09). 홈·전적 마지막 경기 범례에 상대 유효슛 + "유효 = 골문 안으로 간 슛"(04, 06). 선수 평점 위 "이름 앞 배지는 선수 카드의 시즌이에요"(11).
- **"VS" 문구**: 내 정보·첨부·작성 화면·비교 화면 제목을 "비교"로(14).
- **칩**: 경기 성향 진단을 중립 1종 + 좋음(초록)·나쁨(빨강) 2색 캡슐로(07).
- **광고 컨테이너**: 50pt 배너 기준 약 92pt → 약 82pt(07). 검은 띠는 테스트 소재 자체의 테두리였다.
- **온보딩 1·2쪽**: 시스템 아이콘 대신 전적 헤더·홈 "내 구단" 카드 미리보기(01, 02). 3쪽과 같은 카드 겉모양.
- **문장 줄표**: 패배 원인·처방 문장(앱에서 만드는 문구)과 내 정보의 " — "를 쉼표로. 내 정보 🔥 이모지 → SF 심볼.

## 못 본 화면 확인 (2026-11-21, 커밋 7341698 뒤)

캡처 15~27, 전용 시뮬레이터. 15~16은 공개 API에서 조건에 맞는 실제 승리 경기를 골라 딥링크로 열었다.

| 확인한 것 | 결과 |
|---|---|
| 이긴 경기 위험 줄 | 슛 4:7 승리 → "다만 슛은 4 대 7로 밀렸어요…"(15), 유효슛 5:7 승리 → "다만 유효슛은 5 대 7로…"(16). 점유율 조건만 걸리는 경기는 데이터에 없어 못 봤다. |
| 전적 스타일 탭 | 정상(17). 서버 칩 문구의 " — " → " · "로 표시(18). |
| 전적 리포트 탭 | 득실차 폼 그래프가 왼쪽=최신이라 위 "최근10" 줄(오른쪽=최신)과 반대였다 → 뒤집고 "과거 → 최신"(20). 진단 문장의 " — " → 쉼표(19). |
| 전적 선수 탭 | "(n=20)" → "랭커 20경기 기준", 줄 중간에서 끊기지 않게 묶음(22). 랭커 표본 5경기 미만이면 비교 줄을 숨긴다("랭커 1경기"로 "경기당 골 -2.75"가 떴다). |
| 등급 카드 시트 | 정상(23). 닫기 버튼이 없어 손잡이(드래그 표시)를 켰다. |
| 시스템 공유 시트 | 맨 위 미리보기가 빈 아이콘·제목 없음 → 카드 썸네일 + "FC SCOPE 카드"(24). |
| 친구 비교 | 빈 화면·결과 정상(25, 26). 남아 있던 "VS 카드" 문구(공유 버튼·첨부·글 목록·카드 칩) → "비교 카드"/"친구 비교". 카드 그림 속 이름 사이 "VS"는 그대로. |
| 로그인 시트 | "클럽 모집·커뮤니티 참여에는…" → 내 정보와 같은 범위로("커뮤니티 글쓰기·댓글, 스쿼드 보관에는…"). 동의 문장의 밑줄(링크처럼 보이지만 체크만 됨)을 뺐다(27). |
| 공용 시뮬레이터 Ribatto | 기록상 제 입력이 Ribatto 화면에 닿은 건 빈 곳 길게 누르기 1번(화면 변화 없음)과 탭바 근처 빈 곳 탭 1번(앱 전환 직전이라 어느 앱에 닿았는지 불확실)이다. 하이라이트 릴 생성은 그 뒤 다른 세션이 시작한 것으로 보인다. 지금은 Ribatto 편집 화면이 정상으로 떠 있다. |

### 고치지 않은 것(결정 필요)
- 스타일·리포트·선수 탭 광고는 여전히 큰 소재(320×100)다. 홈·경기 목록은 320×50으로 줄였는데 같은 전적 화면 안에서 크기가 다르다. 수익과 맞물려 그대로 뒀다.
- 누적 슛맵의 금색 점(골) 범례가 없다.
- 공유 시트 아래 "서버를 거치지 않아 바로 만들어져요"는 개발자 말투지만 개인정보 안내 의미가 있어 두었다.
- 광고는 테스트 소재라 실제 노출 소재는 확인할 수 없다.
