## 3. 남은 P0/P1 (P0 없음)

1. **P1 시즌 배지가 뭔지 모르겠음** — `10`, `11`, `16`
   - 26TS·WS·WB·FAC·SPT·PTG·DCB… 이름 앞 네모가 20개 넘게 나오는데 하나도 모르겠음.
   - 고칠 방법: 배지를 누르면 시즌 이름 시트가 뜨게 하고, 리포트 표 위에 "배지를 누르면 시즌 이름" 한 줄 달기. 아니면 리포트에서는 배지를 빼기.
2. **P1 유효슛 설명이 화면에 없음** — `08`, `13`, `14`
   - 리포트 맨 위 칸 "유효슛 · 나/상대"가 핵심 숫자인데, 무슨 뜻인지 어디에도 안 나옴.
   - 고칠 방법: 리포트 히어로의 유효슛 칸에 ⓘ를 달거나, 홈 카드 범례를 "유효 8(골문 안으로 간 슛)"으로 바꾸기. 처음 보는 화면인 홈에 먼저 넣기.
3. **P1 "계급"이 뭔지 모름, 이름도 섞여 있음** — `06`, `19`
   - "계급 카드"를 누르면 뭐가 나오는지 상상이 안 됨. 내 정보에는 아직 "VS"라고 써 있음.
   - 고칠 방법: 버튼을 "내 계급 카드"로 바꾸고 작게 "공유용 등급 이미지" 같은 설명 달기. 19의 "전적·VS"는 "전적·비교"로 바꾸기.
4. **P1 커뮤니티는 여전히 비어 있음** — `18`
   - 고칠 방법: 운영자 글은 "공지·예시"로 접기. 매치 리포트에서 "이 경기 평가받기"로 바로 글을 쓸 수 있게 이어주기.
