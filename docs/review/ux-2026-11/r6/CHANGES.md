# R5 → R6 에서 고친 것 (첫 설치부터 한 빌드로 다시 찍음)
- 카드 테두리 2종으로: 보통(회색) · 강조(잔디 초록). Panel 의 highlight 색은 "강조"로만 쓴다.
- 섹션 제목 색 1종(회색) — 남색·초록·금색 라벨 제거.
- 전적 헤더: "계급" → "계급 카드", "VS" → 사람 아이콘 + "비교", 승률 옆 "몰수 빼면 48%" 상시 표시(02).
- 광고: 홈·전적 첫 화면 미리 받기를 320×50 으로, 콘텐츠 등급 최대 PG(10대 사용자).
- 온보딩 3쪽: 아이콘 대신 실제 경기 카드 모양 미리보기(01).
- 슛맵 범례에 "유효슛 = 골문 안으로 간 슛".
- 스쿼드: 아래 90pt 를 흐리게 해 유리 탭바 밑으로 글자가 비치지 않게(03).
- 커뮤니티: 같은 동작 버튼 중복 제거 — 안내 문구만 두고 글쓰기 버튼 하나(04).
