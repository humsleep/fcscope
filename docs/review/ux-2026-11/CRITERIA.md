# FC SCOPE 사용자 패널 평가 기준 (2026-11)

목표: "실제로 깔고 3일 뒤에도 남겨 둘 앱인가"를 냉정하게 판정한다. 비교 대상은 피온북(평가 1.8만, 4.6점),
FotMob·Sofascore 같은 상위 축구 앱, 넥슨 공식 데이터센터다. 의심이 들면 낮게 준다.

## 패널
- **P1 민준(24)** — FC온라인 7년차, 공식경기 챔피언스권. 피온북·데이터센터를 매일 쓴다. 정보 가치·속도·정확성에 엄격.
- **P2 서연(16)** — 친구 따라 FC온라인을 시작한 지 3개월. 용어(스코어·폼 티어·POTM)에 약하다. 첫 실행 이해도와 친절함을 본다.
- **P3 시니어 모바일 UX 리드** — App Store 피처드 심사 경험. HIG·위계·일관성·접근성·완성도·"AI가 만든 티"를 본다.

## 채점 (각 1~10, 정수)
1. 첫인상·이해도 — 처음 30초 안에 무슨 앱이고 뭘 하면 되는지 알 수 있나
2. 핵심 작업 — 내 전적 확인 → 경기 원인 파악 → 공유까지 막힘 없이 되나
3. 정보 가치 — 다른 앱/데이터센터 대신 이걸 매일 열 이유가 있나
4. 시각 완성도 — 축구 앱다운 개성, 위계, 여백, 일관성. AI 템플릿 느낌이 없나
5. 신뢰·피로 — 광고·빈 공간·어색한 문구·숫자 의미 불명이 신뢰를 깎지 않나

**종합** = 다섯 항목 평균(소수 1자리). **통과선: 패널 3명 모두 종합 8.0 이상, P0 없음.**

## 문제 등급
- **P0** — 사용을 멈추게 하거나 오해를 부른다(잘못된 정보, 막힌 흐름, 의미를 알 수 없는 핵심 숫자).
- **P1** — 3일 안에 지우게 만드는 불편·빈약함.
- **P2** — 다듬으면 좋은 것.

각 문제는 캡처 파일명 + 구체적 고칠 방법을 단다. 칭찬은 한 줄로 끝낸다.
