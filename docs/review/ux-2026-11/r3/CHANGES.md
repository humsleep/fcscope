# R2 → R3 에서 고친 것
(01~04 온보딩 캡처는 R2와 같은 화면이라 그대로 복사했다 — 이번 라운드에 온보딩 코드 변경 없음)
- 매치 리포트: 슛맵과 팀 스탯 사이 300×250 광고 제거 → 리포트 맨 끝 작은 배너로.
- 몰수 경기 행: 경기력 숫자 대신 "—", 점유율 대신 "몰수 · 상대 이탈 등".
- 숫자 이름: "경기력"·"넥슨 평점" 두 개로만. 마지막 경기 카드의 "POTM/선수 평점" → "최우수 선수 · 우리 팀/상대 팀", "넥슨 평점". 리포트 "선수 평점" → "선수별 넥슨 평점".
- 경기력 타일에 ⓘ(탭하면 계산 방식·평균 구간 설명, 06 캡처).
- 전적 헤더: "요즘 흐름" 띠 제거(요소 수 축소). 폼 점수 "47점" → "47/100".
- 마지막 경기 카드: 슛맵 로딩 중 회색 상자 대신 같은 크기의 잔디 자리(레이아웃 밀림 방지).
- 스쿼드: 끝까지 내리면 탭바와 겹치지 않음을 확인(13 캡처) — R2의 겹침은 스크롤 중 반투명 탭바 아래로 지나가는 장면이었다.
